# say 字段 TTS 读法约定（单一真源）

> 本文件是 **lecture-jianggao**（讲稿台词）与 **lecture-yaml**（YAML `say` 字段）共享的朗读规则**权威定义**。
> 两个 agent 开工前**必读一遍**。要改 say 读法规则，**只改这一处**——不要再回到 agent 文件里复制。
>
> **适用对象**：会被 TTS 念出来的文本——讲稿台词、YAML 的 `say` 字段。
> **不适用**：YAML 的 `show.body`（板书 LaTeX，归 lecture-yaml 自己的 show.body 约定）。

---

## 0. 最高原则：高中生一耳朵听懂

一句话被 TTS 念出来，一个**没学过大学课程的普通高三学生**要能一耳朵听懂。下面所有规则都是这条原则的实例。遇到规则没覆盖的场景，按这条判断：拿不准就写全称、改中文同义词，宁啰嗦也不要让学生听不懂。

## 1. 数学符号的口语读法

**所有数学符号必须翻译成口语，不能出现 LaTeX。**

### 分式：「X 分之 Y」（分母在前、分子在后）

**不要**「Y 除以 X」、不要「Y 比 X」。

| 数学形态 | 口语 |
|---|---|
| `1/2` | 二分之一 |
| `α/2` | 二分之 alpha |
| `(3/2)k` | 二分之三 k |
| `√3/3` | 三分之根号三 |
| `2π/3` | 三分之二派（或 一百二十度） |

### 三角 / 根号 / 幂 / 对数 / 关系符

| 数学形态 | 口语 |
|---|---|
| `sin θ` | sine 西塔 |
| `cos A` | cosine A |
| `tan C` | tangent C |

> ⚠️ **say 里绝不允许出现 `sin`/`cos`/`tan` 缩写**——TTS 会读成中文谐音（如 "sin" 读成 "森"）。必须写全称 `sine`/`cosine`/`tangent`，紧跟变量名时不加空格（如 `sineA`、`cosineB`、`tangentC`）。详见 §5 中英无空格规则。

| `√5` | 根号五 |
| `x²` | x 的平方 |
| `sin²A` | sineA 的平方（**不要写 "sine 平方 A"**） |
| `cos²B` | cosineB 的平方（**不要写 "cosine 平方 B"**） |
| `≥ / ≤` | 大于等于 / 小于等于 |
| `∈` | 属于 |
| `⇒` | 推出 / 所以 |
| `⇔` | 等价于 |
| `log` | 罗格 |
| `ln` | looen（不要写"以e为底的对数"或"自然对数"） |
| `e` | 欧拉数 e（首次说全名，后续可省） |
| `i` | i（虚数单位） |
| `S_{△ABC}` | 三角形 ABC 的面积 |
| `f'(x)` | f撇x（不要写"f的导数"或"f prime x"） |
| `30°` | 30度（不要写"30°"或"30度°"） |
| `{x \| ...}` | 解集是...（不要逐字符念"大括号x竖线"） |
| `(a,b)` | a到b的开区间（`[a,b]` → a到b的闭区间） |

## 2. 向量本体 vs 向量的模（最易翻车，务必读懂）

⚠️ **核心区分**：`\vec{OA}` 和 `|\vec{OA}|`（或 `|OA|`）是**两个完全不同的对象**——前者是向量（有方向的箭头），后者是它的模长（一个标量数字）。读音必须区分。

| 公式形态 | TTS 该读作 |
|---|---|
| `\vec{OA}` | **向量OA** |
| `\|\vec{OA}\|` 或 `\|OA\|` | **OA的模**（或 OA的长度） |
| `2\vec{OA}` | **两倍向量OA** |
| `\frac{1}{2}\vec{a}` | **二分之一倍的向量a**（不要省"倍的"） |
| `2\|\vec{OA}\|` | **两倍OA的模** |
| `\vec{OA}+\vec{OB}` | 向量OA加向量OB |
| `\|\vec{OA}\|+\|\vec{OB}\|` | **OA的模加OB的模** |
| `(\|OA\|+r)/\|OB\|` | **OA的模加r再除以OB的模** |

**判断方法**：看这个量在原公式里**是否被 `|…|` 包裹**——
- 没被 `|…|` 包裹的 `\vec{XX}` → 是向量 → 读"向量XX"
- 被 `|\vec{XX}|` 或 `|XX|` 包裹 → 是模长（标量）→ 读"XX的模"

**致命错误（数学不通，绝不能犯）**：

| ❌ 错误 | ✅ 正确 |
|---|---|
| 向量OM加r（向量＋标量？） | OM的模加r |
| 向量ON大于等于向量OM（向量没有大小关系） | ON的模大于等于OM的模 |
| 分子是向量ON，分母是向量OM | 分子是ON的模，分母是OM的模 |

**向量本体的前缀规则**：未被 `|…|` 包裹的 `\vec{X}`，在 say 里**必须前缀"向量"**（首次出现 + 每个新公式开头 + 关键结论；连续提及可省略避免啰嗦）。

| ✅ 正确 | ❌ 错误 |
|---|---|
| 向量a等于向量OA | a等于OA（学生分不清标量还是向量） |
| 向量a点乘向量b | a点乘b |
| 向量AB减向量CA | AB减CA |
| 两倍向量c | 2c |

宁可多说"向量"也不要省——但**只对向量本体**。模长（`|…|` 内）不要写"向量"，否则数学不通。

## 3. 希腊字母音译（CosyVoice 友好）

中文 TTS 对希腊字母英文名读法不稳定，固定音译：

| 符号 | say 写法 |
|---|---|
| `\pi` | 派（**不要写 π / pi / pai**） |
| `\theta` | 西塔（**不要写 theta**——读法不稳） |
| `\alpha` | alpha |
| `\beta` | beta |
| `\lambda` | lambda |
| `\gamma` | gamma |
| `\delta` | delta |
| `\mu` | 谬（**不要写 miu**） |
| `\phi` | phi |
| `\omega` | omega |

**经验法则**：某个希腊字母在测试视频里读不稳（每次发音不同、或被分字母读）→ 换中文音译。`\theta` 已确认不稳，固定"西塔"。

## 4. 数字读法（个位交脚本，多位写汉字基数）

say 最终经 TTS 念，阿拉伯数字会被误读（`2m`→两米、`120`→一二零）。

- **个位数字 + 计量单位**：由下游确定性脚本 `normalize_say.py`（pipeline Step 3.5）统一规范化（`2x`→`二x`、`2m`→`二M`）。**你不必逐个纠结个位数。**
- **多位数（≥2 位）**：脚本**故意不碰**（基数读法"一百二十" vs 逐位"一二零"依赖语义）。凡多位数**必须你自己写成汉字基数**：

| 写法 | 写成 |
|---|---|
| 120 度 | 一百二十度 |
| 1235 | 一千二百三十五 |
| 第 14 问 | 第十四问 |

## 4A. 物理量与单位的读法（物理题专用）

> 物理题的 say 除遵守以上各节外，还要过本节。核心口诀：**量的符号写字母，单位写汉字**。

### 单位一律写汉字（TTS 对单位字母读法极不稳）

| ✅ say 写法 | ❌ 错误（TTS 读不准/胡读） |
|---|---|
| 六伏 / 零点三安 / 十欧 | 6V / 0.3A / 10Ω |
| 零点四瓦 / 五焦 / 二牛 | 0.4W / 5J / 2N |
| 摄氏二十度（20℃） | 20℃ / 20度C |
| 三乘十的八次方米每秒 | 3×10⁸m/s / 3e8 |
| 五十赫兹 / 一千帕 | 50Hz / 1000Pa |

常用单位对照：伏（V）、千伏、毫伏、安（A）、毫安、欧（Ω）、千欧、瓦（W）、千瓦、千瓦时（度）、焦（J）、牛（N）、米、厘米、毫米、千米、秒、小时、赫兹、帕、库仑、摄氏度。

**量值写法**：数值按 §4 规则（个位数可交脚本，多位数/小数自己写汉字），紧跟汉字单位，如"二十欧""零点二安"。

### 物理量符号：字母保留，下标转平写

| 公式形态 | TTS 该读作 |
|---|---|
| `U` / `I` / `R` / `F` / `a` / `v` / `P` | 电压U / 电流I / 电阻R / 力F / 加速度a / 速度v / 功率P（首提带量名，后文可只念字母） |
| `R_1` / `U_1` | R1 / U1（下标平写，禁下划线） |
| `U_R`（R 两端的电压） | R两端的电压（**不要读"U下标R"**） |
| `I_1^2` / `v_0` | I1的平方 / 初速度v0（或 v零） |
| `R_max` | 最大阻值（不念字母） |
| `mg` / `qU` | mg / qU（连写可，紧跟量名说明"重力mg"） |

### 物理术语口诀（高频易错）

| ✅ 正确 | ❌ 错误 |
|---|---|
| 欧姆定律（首提全名，后可说"欧姆定律"） | 欧律 / Ohm's law |
| 电流的平方乘以电阻 | I方R / I平方R（say 里少念字母公式，多念量名） |
| 摩擦因数 | 摩擦系数（新课标教材用"因数"） |
| 动摩擦因数缪 | μ（直接念符号） |
| 西塔（角位移/角度） | theta |
| 欧米伽 / omega | ω |
| 电功率 / 热功率 | power |
| 千瓦时（口语可说"度"） | kwh / 度电 |

**字母物理量与汉字之间不留空格**（同 §5）："电阻R1的阻值"、"力F的方向"，不是"电阻 R1 的阻值"。

## 5. 中文与英文/数字之间**禁止空格**

CosyVoice 把空格当作微停顿提示。中英 / 中数边界留空格 → TTS 念出来断断续续。

| ✅ 写法 | ❌ 卡顿 |
|---|---|
| 向量OM等于两倍c | 向量 OM 等于 2c |
| 二分之三k | 二分之三 k |
| sineA加cosineB | sine A 加 cosine B |
| 四倍c的模 | 4 倍 c 的模 |
| lambda小于等于九 | lambda 小于等于 9 |

**规则**：中文字符与英文字母/阿拉伯数字相邻时不留空格。停顿一律用全角标点（，。、——）传达，不靠空格。
例外：英文术语内部空格保留（如 "Q.E.D."——几乎用不到）。

**例外：三角函数名与变量之间必须加空格**

当 `sine`/`cosine`/`tangent` 等英文函数名后面跟变量字母时，函数名和变量之间必须加空格，防止 TTS 连读：

| ✅ 正确写法 | ❌ 错误（TTS 连读） |
|---|---|
| sine A | sineA |
| cosine B | cosineB |
| tangent C | tangentC |
| sine A 乘 cosine A | sineA乘cosineA |
| 二 sine A 乘 cosine A | 二sineA乘cosineA |

**规则**：`sine`/`cosine`/`tangent` 与后面的变量字母之间**必须加空格**。多个三角函数表达式相邻时，每个都要加空格。

## 6. 小问编号：圈号全禁用，say 与上屏均转写

**圈号 ①②③④ 在 `show.body` / `statement` 渲染后显示为方框**（模板的 CJK 字符类声明对该字符段实际无效），**`say` 里 TTS 也读不稳**，两处均禁用。

转写方式：

| ❌ 禁用 | ✅ show.body（LaTeX） | ✅ say（TTS） |
|---|---|---|
| ① ② ③ ④ | `\text{式1}` `\text{式2}` | 第一式/第二式 或 (i) (ii) |
| ⅰ ⅱ ⅲ | 同上 | (i) (ii) (iii) |

方程编号示例：`$\quad \cdots \text{式1}$` 渲染为"……式1"，清晰可靠。

## 7. 标点：全角，禁双引号

| 用途 | 写法 |
|---|---|
| 短停顿（逻辑分隔） | 全角逗号 `，` |
| 句末 | 全角句号 `。` |
| 强转折/强调 | 全角破折号 `——` |
| 问句 | 全角问号 `？` |
| 列举 | 全角顿号 `、` |

**禁止**：ASCII 半角逗号 `,` / 半角句号 `.` / 单字 `-`（TTS 不识别为停顿）；省略号 `……`（各 TTS 处理不一）；英文双引号 `"`（破坏 YAML / TTS 不读）；空格充当停顿（见第 5 条）。

## 8. say 里**禁止出现**的字符（自检红线）

- ❌ LaTeX 残留：`$ \ ^ _ °`（包括下划线，如 `k_AB` → 应写"AB的斜率"）
- ❌ Unicode 数学符号：`π √ ≥ ≤ ≠ ∈ ∞ ± ×`
- ❌ 物理单位符号（§4A）：`Ω V A W J N ℃ Hz`（写汉字：欧/伏/安/瓦/焦/牛/摄氏度/赫兹）；`μ` 写"缪"或"微"
- ❌ 英文数学缩写：`sin cos tan log ln pi`（除非明显是变量名）→ 替换方案见 §1 和 §9
- ❌ 英文术语缩写：`LHS RHS w.r.t. s.t. iff Q.E.D. WLOG`（学生听不懂）
- ❌ 英文双引号 `"`

全部按上面各节口语化 / 中文化。

**下标/角标处理**：say 里不能出现下划线表示下标。正确说法：
- `k_AB` → "AB的斜率"或"AB斜率"
- `x_1` → "x1"
- `a_n` → "an"

## 10. 内容原则（说什么 & 不说什么）

> 以下规则控制 **say 的内容边界**，不是发音规则，但直接影响 TTS 质量和学生体验。

| ✅ 该做 | ❌ 不做 |
|---|---|
| 公式自然引出：用到什么就说什么 | 单独铺垫"我们来看这个公式" |
| 直接从题目出发 | 回顾前置知识（学生看视频前已学过微课） |
| 聚焦本题解法 | 盘点"易错点""避坑指南" |
| 正常讲解 | 讲发音元知识（"绝对值怎么念""这个符号读作…"） |
| 题目确实需要时才总结 | 硬塞口诀/心法/顺口溜 |
| | 念题源标注：`（人教A版...）` 不进 say |

**核心**：say 只讲**本题怎么解、为什么这么解**。元知识、题源、铺垫、口诀都是噪音。
