# 备课笔记 · 襄阳四中期中 Q17 · 菱形中的向量

## 一、题目

在菱形 $ABCD$ 中，$|\vec{AB}| = 6$，$\angle BAD = 60°$，$\vec{BE} = \frac{1}{2}\vec{BC}$，$\vec{CF} = 2\vec{FD}$。

(1) 若 $\vec{EF} = x\vec{AB} + y\vec{AD}$，求 $3x + 2y$ 的值；
(2) 求 $\vec{AC}\cdot\vec{EF}$ 的值；
(3) 若 $P$ 是线段 $EF$ 上的动点，则 $\vec{AP}\cdot\vec{AC}$ 是否为定值？若是，求该定值；若不是，求 $\vec{AP}\cdot\vec{AC}$ 的取值范围。

## 二、题目定位

- **题型**：解答题中档·向量综合·定值/取值范围
- **核心考点**：基底分解、向量数量积、菱形中对边关系、动点定值判断
- **难度**：★★★☆☆
- **分值权重**：15 分（4 + 5 + 6）

## 三、完整解法（专家版）

### 整体思路
菱形给定了两条相邻边 $\vec{AB}$ 和 $\vec{AD}$ 的模和夹角，天然是一对基底。整道题的核心是**选定基底 → 把所有向量用基底线性表出 → 代数计算**。基底思想贯穿三问，是向量章节最核心的哲学。

### 设基底 + 基本量
记 $\vec{m} = \vec{AB}$，$\vec{n} = \vec{AD}$。基本量：
- $\vec{m}^2 = \vec{n}^2 = 36$
- $\vec{m}\cdot\vec{n} = 6\cdot 6\cdot\cos 60° = 18$

### 第 (1) 问
$\vec{EF} = \vec{EC} + \vec{CF}$。

菱形对边：$\vec{BC} = \vec{AD} = \vec{n}$，$\vec{CD} = -\vec{AB} = -\vec{m}$。

$\vec{EC} = \frac{1}{2}\vec{BC} = \frac{1}{2}\vec{n}$（因 $E$ 是 $BC$ 中点）

$\vec{CF} = \frac{2}{3}\vec{CD} = -\frac{2}{3}\vec{m}$（因 $F$ 把 $CD$ 分 2:1，靠 $D$ 侧）

故 $\vec{EF} = -\frac{2}{3}\vec{m} + \frac{1}{2}\vec{n}$，即 $x = -\frac{2}{3}$, $y = \frac{1}{2}$。

$3x + 2y = -2 + 1 = -1$。

### 第 (2) 问
$\vec{AC} = \vec{m} + \vec{n}$（菱形对角线）。

$\vec{AC}\cdot\vec{EF} = (\vec{m} + \vec{n})\cdot(-\frac{2}{3}\vec{m} + \frac{1}{2}\vec{n})$

$= -\frac{2}{3}\vec{m}^2 + \frac{1}{2}\vec{m}\cdot\vec{n} - \frac{2}{3}\vec{n}\cdot\vec{m} + \frac{1}{2}\vec{n}^2$

$= -\frac{2}{3}(36) + (\frac{1}{2} - \frac{2}{3})(18) + \frac{1}{2}(36)$

$= -24 - 3 + 18 = -9$。

### 第 (3) 问
$P$ 在 $EF$ 上，设 $\vec{EP} = t\vec{EF}$，$t \in [0, 1]$。

$\vec{AP} = \vec{AE} + t\vec{EF}$

$\vec{AE} = \vec{m} + \frac{1}{2}\vec{n}$（因 $\vec{AE} = \vec{AB} + \vec{BE}$）

$\vec{AP}\cdot\vec{AC} = \vec{AE}\cdot\vec{AC} + t\cdot\vec{EF}\cdot\vec{AC}$

$\vec{AE}\cdot\vec{AC} = (\vec{m} + \frac{1}{2}\vec{n})(\vec{m} + \vec{n}) = 36 + 18 + 9 + 18 = 81$

$\vec{EF}\cdot\vec{AC} = -9$（由第 2 问）

$\vec{AP}\cdot\vec{AC} = 81 + t\cdot(-9) = 81 - 9t$

**表达式含 $t$，不是定值**。$t \in [0, 1]$：
- $t = 0$（$P = E$）：$\vec{AP}\cdot\vec{AC} = 81$
- $t = 1$（$P = F$）：$\vec{AP}\cdot\vec{AC} = 72$

取值范围：$[72, 81]$。

## 四、前置知识清单

1. **平面向量的基底表示**：任意向量可唯一表示为两个不共线基底的线性组合
   - 本题用法：整道题的骨架——用 $\vec{m}, \vec{n}$ 表示一切
   - 熟练程度：条件反射级

2. **向量数量积的定义和运算律**：$\vec{u}\cdot\vec{v} = |\vec{u}||\vec{v}|\cos\theta$，分配律、交换律成立
   - 本题用法：第 (2) 问 的核心工具
   - 熟练程度：必须

3. **菱形的边关系**：对边平行且相等但方向相反（$\vec{BC} = \vec{AD}$，$\vec{CD} = -\vec{AB}$），四边相等
   - 本题用法：第 (1) 问把 $\vec{EC}, \vec{CF}$ 换成基底表达
   - 熟练程度：必须熟练

4. **分点公式**：$\vec{CF} = 2\vec{FD}$ 意味着 $F$ 把 $CD$ 分 2:1，$\vec{CF} = \frac{2}{3}\vec{CD}$
   - 本题用法：确定 $F$ 相对 $C, D$ 的位置
   - 熟练程度：必须，分式要反应快

5. **线段参数化**：动点 $P$ 在线段 $XY$ 上 $\Leftrightarrow \vec{XP} = t\vec{XY}$, $t\in[0,1]$
   - 本题用法：第 (3) 问的动点建模
   - 熟练程度：必须

6. **定值问题的判断原则**：参数消得掉 = 定值，消不掉 = 看范围
   - 本题用法：第 (3) 问判断逻辑
   - 熟练程度：理解即可

## 五、学生卡点地图

### 卡点 1：菱形中 $\vec{CD}$ 的方向
- **位置**：第 (1) 问求 $\vec{CF}$ 时
- **原因**：学生容易以为 $\vec{CD} = \vec{AB}$（同向），忽略菱形对边是反向的
- **破解**：画菱形图，用箭头标出 $\vec{AB}$ 和 $\vec{CD}$——两者平行但**箭头相反**。对边向量关系是：$\vec{AB} = -\vec{CD}$ 或 $\vec{AB} = \vec{DC}$

### 卡点 2：$\vec{CF} = 2\vec{FD}$ 的比例理解
- **位置**：第 (1) 问
- **原因**：学生看到 $2\vec{FD}$ 容易把 $F$ 的位置搞错（偏 $C$ 还是偏 $D$）
- **破解**：
  - 从方向看：$\vec{CF}$ 和 $\vec{FD}$ 同向（都沿 $CD$），说明 $F$ 在 $CD$ 内部
  - 从长度看：$|\vec{CF}| = 2|\vec{FD}|$，$F$ 离 $D$ 近，所以 $CF:FD = 2:1$，$\vec{CF} = \frac{2}{3}\vec{CD}$

### 卡点 3：展开数量积时漏项或合并错
- **位置**：第 (2) 问 $(\vec{m}+\vec{n})\cdot(-\frac{2}{3}\vec{m}+\frac{1}{2}\vec{n})$
- **原因**：展开四项后，学生容易漏合并 $\vec{m}\cdot\vec{n}$ 的两项系数（$\frac{1}{2}$ 和 $-\frac{2}{3}$）
- **破解**：展开成四项写清楚，用括号圈出同类项，合并系数再代入基本量

### 卡点 4：第 (3) 问"定值 vs 非定值"的判断
- **位置**：算出 $\vec{AP}\cdot\vec{AC} = 81 - 9t$ 后
- **原因**：
  - 学生可能没意识到表达式含 $t$ 就不是定值
  - 或者有些学生以为求定值题"肯定是定值"，不敢写"不是定值"
- **破解**：
  - 强调"**参数消不掉就不是定值**"，这是机器级的判断规则
  - 题目本身问"是否为定值"，就允许"不是"作为答案

### 卡点 5：取值范围的闭区间
- **位置**：第 (3) 问最后
- **原因**：$t \in [0, 1]$ 是闭区间（$P$ 可以取到端点 $E$ 和 $F$），学生可能漏端点
- **破解**：明确"$P$ 是线段上的点，包括两端"，所以 $t$ 闭。表达式关于 $t$ 线性，端点代入即可

## 六、关键跳跃点（Why 慢镜头）

### 跳跃 1：基底选择——为什么是 $\vec{AB}$ 和 $\vec{AD}$
- **表象**：解题一开始就设 $\vec{m} = \vec{AB}$，$\vec{n} = \vec{AD}$
- **Why**：**好的基底满足三个条件**——(1) 题目给出模，(2) 题目给出夹角，(3) 它们不共线。菱形的相邻两边 $\vec{AB}$ 和 $\vec{AD}$ 三者全满足，是天选基底。选错了（比如选对角线）后面全部计算加倍难。
- **迁移价值**：**向量综合题第一步永远是选基底**。选那对"模和夹角都已知的不共线向量"。
- **样板台词**：「向量题选基底就像盖楼选地基——选对了后面顺风顺水，选错了推倒重来。通用原则：挑那对已知模、已知夹角、不共线的向量。」

### 跳跃 2：第 (3) 问 的参数化动点
- **表象**：设 $\vec{EP} = t\vec{EF}$，$t \in [0, 1]$
- **Why**：动点在线段上，最自然的刻画是用一个比例参数把动点表达出来。$t = 0$ 是起点 $E$，$t = 1$ 是终点 $F$，中间都是线段内部点。**一个参数就完全刻画了动点的所有可能位置**。
- **迁移价值**：**任何动点问题 → 先用一个参数表达出位置**。动点在线段上用 $t \in [0,1]$，在射线上用 $t \geq 0$，在直线上用 $t \in \mathbb{R}$。
- **样板台词**：「动点题怕的不是点在动，是不知道怎么描述它动。用一个参数把所有位置串起来——这是动点问题的通用建模。」

### 跳跃 3：定值问题的通用判断
- **表象**：算出 $\vec{AP}\cdot\vec{AC} = 81 - 9t$ 后直接判"非定值"
- **Why**：定值的定义就是"和参数无关"。用参数 $t$ 把所有情形统一表达后，**表达式里还留着 $t$ 的就是非定值**。反过来如果某种巧合让 $t$ 的系数变 0，那就是定值。
- **迁移价值**：**定值/非定值问题的机器级判断**——设参数 → 算表达式 → 看参数消不消。
- **样板台词**：「定值问题不要靠直觉。设参数、算表达式、看参数在不在——这是一条傻瓜规则，但比直觉可靠一百倍。」

## 七、易错点

1. **菱形对边方向搞反**
   - 位置：第 (1) 问 $\vec{CD}$ 的方向
   - 原因：和平行四边形"对边相等"记混
   - 避免：向量是有向线段。平行是方向关系，相等是方向+长度。对边**平行且长度相等，但首尾位置倒过来，所以向量反向**

2. **分点系数算错**
   - 位置：第 (1) 问 $\vec{CF} = \frac{2}{3}\vec{CD}$
   - 原因：$\vec{CF} = 2\vec{FD}$ 看成 $\vec{CF}:\vec{CD} = 2:1$
   - 避免：正确的比例是 $\vec{CF}:\vec{FD} = 2:1$，$\vec{CF}:\vec{CD} = 2:3$

3. **数量积展开系数错**
   - 位置：第 (2) 问 $\vec{m}\cdot\vec{n}$ 的合并系数
   - 原因：$(\vec{m} + \vec{n})(-\frac{2}{3}\vec{m} + \frac{1}{2}\vec{n})$ 中间两项是 $\frac{1}{2}\vec{m}\vec{n}$ 和 $-\frac{2}{3}\vec{n}\vec{m}$，合并系数 $\frac{1}{2} - \frac{2}{3} = -\frac{1}{6}$，不是 $-\frac{1}{6}$ 之外的值
   - 避免：展开成四项写出，合并后再代入

4. **第 (3) 问答案写成"定值"**
   - 位置：第 (3) 问结论
   - 原因：考生潜意识里"求定值题就是定值"
   - 避免：按机器规则——参数消不掉就是非定值，直接写"不是定值"+ 给范围

## 八、核心心法

### 心法 1：基底化是向量综合题的灵魂

**平面向量问题，永远先选定两个不共线基底，把所有向量用基底线性表出，把几何问题降维到代数计算。**

核心要点：
- 选基底：模和夹角已知、不共线
- 算基本量：$\vec{m}^2$, $\vec{n}^2$, $\vec{m}\cdot\vec{n}$ 三个常数，贯穿全题
- 所有向量转译成 $x\vec{m} + y\vec{n}$ 形式
- 所有数量积变成 $x_1 x_2 \vec{m}^2 + (x_1 y_2 + x_2 y_1)\vec{m}\vec{n} + y_1 y_2 \vec{n}^2$ 的展开

**样板台词**：「几何学家求距离、求夹角，向量学家求系数。基底定了，一切向量题都退化成算术。」

### 心法 2：定值问题的机器规则

**动点定值问题 → 用参数刻画动点 → 计算目标 → 看参数消不消**。
- 消掉：定值
- 消不掉：非定值，看范围

这条规则普适于向量、解析几何、函数。别靠直觉，照规则走。

**样板台词**：「判断定值不要靠猜，也不要靠'应该'。设参数、算式子、看参数——参数消掉就是定值，没消掉就是非定值。这是数学题的'傻瓜算法'，准过任何直觉。」

## 九、讲解推荐路径

1. **读题 + 画图**
   - 画菱形 $ABCD$，标出 $E, F$ 位置
   - 明确 $E$ 是 $BC$ 中点，$F$ 在 $CD$ 上靠 $D$ 侧

2. **建立基底（核心跳跃 1）**
   - $\vec{m} = \vec{AB}$, $\vec{n} = \vec{AD}$
   - 算基本量 $\vec{m}^2 = 36$, $\vec{n}^2 = 36$, $\vec{m}\cdot\vec{n} = 18$——板书强调这三个数贯穿全题

3. **第 (1) 问**
   - 拆解 $\vec{EF} = \vec{EC} + \vec{CF}$
   - 菱形对边关系 → $\vec{EC} = \frac{1}{2}\vec{n}$, $\vec{CF} = -\frac{2}{3}\vec{m}$（卡点 1、2 在此处理）
   - 对应得 $x, y$，算 $3x + 2y = -1$

4. **第 (2) 问**
   - $\vec{AC} = \vec{m} + \vec{n}$ 板书
   - 展开数量积，合并，代入基本量
   - 答案 $-9$

5. **第 (3) 问**
   - 动点建模：$\vec{EP} = t\vec{EF}$，$t \in [0,1]$（核心跳跃 2）
   - $\vec{AE} = \vec{m} + \frac{1}{2}\vec{n}$
   - $\vec{AP}\cdot\vec{AC} = \vec{AE}\cdot\vec{AC} + t\vec{EF}\cdot\vec{AC}$
   - 计算得 $81 - 9t$
   - 判断非定值，算端点得 $[72, 81]$（核心跳跃 3）

6. **终章 · 两条心法**
   - 基底化是向量综合题灵魂
   - 定值问题的机器规则

## 十、备注

- **画图必做**。菱形的对边关系（$\vec{CD} = -\vec{AB}$）必须在图上可视化，否则学生难建立方向感。
- **基本量板书要醒目**。$\vec{m}^2 = 36$, $\vec{n}^2 = 36$, $\vec{m}\cdot\vec{n} = 18$ 这三个数贯穿三小问，应当放在显眼位置，整题计算都要回来查表。
- 第 (3) 问是本题唯一的"动点 + 定值"考点，可以让学生在讲解前自己判断"是定值还是非定值"，再公布答案——这是激活学习的小技巧。
- 题目的设问结构是**递进式**（每一问用到前一问的结果）：第 (2) 问用 $\vec{EF}$，第 (3) 问用 $\vec{EF}\cdot\vec{AC}$。这种结构讲解时要点明——让学生看到解题的**连续性**。
