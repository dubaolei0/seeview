# 备课笔记 · 襄阳四中期中 Q1 · 复数与复平面

## 一、题目

若复数 $z$ 满足 $z\mathrm{i} = -1 + 2\mathrm{i}$，则 $z$ 在复平面内对应的点位于（  ）

A. 第一象限  B. 第二象限  C. 第三象限  D. 第四象限

## 二、题目定位

- **题型**：选择题·复数基础·送分题
- **核心考点**：复数乘除运算、复平面对应点
- **难度**：★☆☆☆☆（送分题）
- **分值权重**：5 分

## 三、完整解法

**两种思路都要会**，考场上哪种顺手用哪种。

**思路一（除法变形）**：两边除 $\mathrm{i}$，分子分母同乘 $\mathrm{i}$ 把分母变实：
$$z = \frac{-1+2\mathrm{i}}{\mathrm{i}} = \frac{(-1+2\mathrm{i})\mathrm{i}}{\mathrm{i}^2} = \frac{-\mathrm{i} + 2\mathrm{i}^2}{-1} = 2 + \mathrm{i}$$

**思路二（待定系数）**：设 $z = a + b\mathrm{i}$，则 $z\mathrm{i} = -b + a\mathrm{i} = -1 + 2\mathrm{i}$。由实部虚部对应：$a = 2$, $b = 1$，$z = 2 + \mathrm{i}$。

对应点 $(2, 1)$，第一象限，选 A。

## 四、易错点 / 基础检查点

做错这题的学生，基本是下面之一：

1. **$\mathrm{i}^2 = -1$ 记混**：算 $(a+b\mathrm{i})\mathrm{i} = a\mathrm{i} + b\mathrm{i}^2$ 时把 $b\mathrm{i}^2$ 当成 $b$ 没变号。
2. **复数相等方程组对错**：$-b + a\mathrm{i} = -1 + 2\mathrm{i}$ 时把 $a$ 和 $b$ 错位配，把"$\mathrm{i}$ 前的系数"和"没带 $\mathrm{i}$ 的部分"混。
3. **复平面 $(a,b)$ 对应错**：$z = 2 + \mathrm{i}$ 应对应 $(2, 1)$，有学生会写成 $(1, 2)$。
4. **除法变形时忘了把分母实数化**：只是两边除 $\mathrm{i}$ 就停住，得到 $z = (-1+2\mathrm{i})/\mathrm{i}$ 的形式就交卷了。

## 五、讲解要点

**要讲两种方法，不是一种**。这不是为了这道题，是为了建立学生日后所有复数题的"两把刀"——代数变形（快）和待定系数（稳）。

关键要铺三个知识点：
- $\mathrm{i}^2 = -1$（复数的地基）
- 复数相等 ⟺ 实部虚部分别相等
- 复平面 $a+b\mathrm{i} \leftrightarrow (a,b)$

**心法**：复数除法的通用套路 = 分子分母同乘分母的共轭，让分母变实。这招覆盖所有复数除法题。

「样板台词：复数题你要有两把刀。一把代数变形（快但要熟悉共轭套路），一把待定系数（稳但步骤多）。考场上哪把顺手用哪把。」
