# 备课笔记 · 圆柱内两等球最大半径

## 一、题目

一个底面半径为 $4$ cm（直径 $8$ cm），高为 $9$ cm 的封闭圆柱形容器内有两个半径相等的铁球，则铁球半径 $r$ 的最大值为 $\underline{\qquad\qquad}$ cm。

## 二、题目定位

- **题型**：立体几何 · 最值 · 约束翻译型
- **核心考点**：空间距离 = 水平分量 + 垂直分量（勾股分解）；极值下所有约束同时取等号
- **难度**：★★★☆☆（中档偏上）
- **权重**：选择/填空压轴位置，通常 5 分

## 三、完整解法（专家版）

核心观察：两球**等径**、要使 $r$ 最大，最优摆法必然是两球**对角贴壁**（球心分居轴两侧，一球贴底、一球贴顶，且两球相切）。因为这种摆法让所有约束同时绷紧。

设圆柱底面半径 $R = 4$，高 $H = 9$。对角摆放下：

- 两球心水平距离 $= 2(R - r)$（各离轴 $R - r$）
- 两球心垂直距离 $= H - 2r$（球心高度分别是 $r$ 与 $H - r$）
- 两球相切：$\text{球心距} = 2r$

建立方程：
$$
[2(R-r)]^2 + (H-2r)^2 = (2r)^2
$$

代入 $R = 4, H = 9$：
$$
4(4-r)^2 + (9-2r)^2 = 4r^2
$$

展开 $4(16 - 8r + r^2) + (81 - 36r + 4r^2) = 4r^2$，即
$$
4r^2 - 68r + 145 = 0
$$

求根公式 $\Delta = 68^2 - 4 \cdot 4 \cdot 145 = 2304 = 48^2$，
$$
r = \frac{68 \pm 48}{8} = 14.5 \text{ 或 } 2.5
$$

$14.5 > R = 4$ 不合理，舍去。所以 $r_{\max} = \dfrac{5}{2}$ cm。

**对照方案**：如果竖直叠放，$4r = H$，$r = \dfrac{9}{4} = 2.25$。对角摆大于叠放，因此答案 $\dfrac{5}{2}$ 才对。

## 四、前置知识清单

1. **空间两点距离分解**：先投影到水平面看水平分量，再看垂直分量，勾股合成
2. **球内切圆柱的约束翻译**：球贴壁 ⇔ 球心到轴距离 $= R - r$；球贴底 ⇔ 球心 $z = r$
3. **一元二次方程求解**：求根公式 + 排除不合理根
4. **约束极值原则**：最优解通常出现在所有约束同时取等号的状态

## 五、学生卡点地图

1. **卡点 A（最致命）**：想不到对角摆放——默认竖直叠放就是最大，算出 $\dfrac{9}{4}$ 就填了
   - **破解**：反问"竖直叠放时，球根本没碰到圆柱壁，是不是还有空间？既然横向没用完，能不能用起来？"

2. **卡点 B**：想到对角摆放但建不出方程——不知道水平分量怎么算
   - **破解**：俯视图——两球心都在直径上对面，各离轴 $R - r$，所以水平距 $= 2(R - r)$

3. **卡点 C**：垂直分量搞错——学生常写成 $H - r$ 或 $H$
   - **破解**：一球心在 $z = r$，另一球心在 $z = H - r$，差 $= H - 2r$

4. **卡点 D**：计算错——$4(4-r)^2$ 忘了乘 4 倍

5. **卡点 E**：不舍根 $14.5$ 或两个都留

## 六、关键跳跃点（Why 慢镜头）

**跳跃 1：从叠放到斜放**
- **表象**：直觉上两球竖着放最自然
- **Why**：要让 $r$ 最大，应该"把所有约束都榨干"——球既要贴壁又要贴底顶，横向和纵向同时被利用，这是极值问题的通用思路
- **迁移价值**：**容器最值问题的核心心法——最优态下所有约束同时取等号**。这一条可以套到很多类似题上（盒内放球、罐内放棒、袋内放棍）
- **样板台词**：「你想，竖着叠放的时候，球根本没碰到圆柱壁，横向空间还没用完。如果我们让球往两边倒，利用壁来撑开球心距，r 会不会更大？最大的秘诀就在这里——让所有约束同时绷紧。」

**跳跃 2：空间距离的勾股分解**
- **表象**：两球心都是 3D 点，距离看着复杂
- **Why**：斜线距离 = 水平投影距离 + 垂直距离的勾股合成。这是把 3D 问题拆成 2D + 1D 的标准招
- **迁移价值**：空间几何中任何斜线长度都可以这样分解
- **样板台词**：「两球心距怎么算？我们把它投影到水平面看：水平分量是 2 倍的 R 减 r，垂直分量是 H 减 2r。然后用勾股定理合起来——水平平方加垂直平方等于斜线平方。」

## 七、易错点

- $2(R-r)$ **平方**要变 $4(R-r)^2$，不是 $2(R-r)^2$
- 展开 $(9-2r)^2 = 81 - 36r + 4r^2$，中间项是 $-36r$，不是 $-18r$
- 合并同类项时 $4r^2 + 4r^2 - 4r^2 = 4r^2$，不是 $8r^2$
- 舍根时要回头检查几何意义（$r$ 不能超过 $R$）

## 八、核心心法

1. **容器最值心法**：最优解发生在所有约束同时取等号时——不要只看一个维度
2. **空间距离勾股分解**：水平分量 + 垂直分量 = 斜距（三维空间两点距离的通用拆法）
3. **极值验证习惯**：解出的答案要回代几何意义检查合理性，不是数学解就合理

## 九、讲解推荐路径

1. 读题 + 指出题型（容器内放球、求最大半径）
2. 先给出"直觉方案"——竖直叠放，算出 $r = 9/4$
3. 反问"这真的是最大吗"——引出关键跳跃：叠放时球没贴壁，空间没用完
4. 引出对角摆放 + 最优约束同时绷紧的心法
5. 方程建立：水平、垂直、勾股
6. 展开求解 + 舍根
7. 验证 + 对比两方案
8. 升华：容器最值问题的通用心法 + 空间距离分解
