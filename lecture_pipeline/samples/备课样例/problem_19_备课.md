# 备课笔记 · 襄阳四中期中 Q19 · 布洛卡点

## 一、题目

若 $\triangle ABC$ 内一点 $P$ 满足 $\angle PAB = \angle PBC = \angle PCA = \theta$，则称点 $P$ 为 $\triangle ABC$ 的布洛卡点，$\theta$ 为 $\triangle ABC$ 的布洛卡角。已知 $\triangle ABC$ 中，$BC=a$，$AC=b$，$AB=c$，点 $P$ 为 $\triangle ABC$ 的布洛卡点，$\theta$ 为 $\triangle ABC$ 的布洛卡角。

(1) 若 $\sin\angle BAC = \frac{3}{5}$，$\sin\theta = \frac{1}{5}$，求 $\frac{PA}{b}$ 的值；

(2) 若 $\triangle ABC$ 为锐角三角形，
    ① 若 $\theta = \frac{\pi}{6}$，求 $\sin(\angle BAC-\theta)\sin(\angle ABC-\theta)\sin(\angle ACB-\theta)$ 的值；
    ② 若 $\angle BAC = \frac{\pi}{3}$，求 $\tan\theta$ 的取值范围。

## 二、题目定位

- **题型**：解答题压轴·情景题·布洛卡点
- **核心考点**：正弦定理（子三角形）、循环对称消元、三角恒等变换、锐角三角形约束、单变量最值
- **难度**：★★★★★
- **分值权重**：17 分（3 + 5 + 9）

## 三、完整解法（专家版）

### 整体思路
布洛卡点 P 把 △ABC 切成三个子三角形：△PAB、△PBC、△PCA。每个子三角形里都有一个角等于 θ，这是三个子三角形之间的**公共桥梁**。对每个子三角形用正弦定理，就能把 PA、PB、PC 和三边 a、b、c 通过 θ 和三个内角串起来。三问都用这一套工具，只是串法不同。

### 角度分布（通用）
- △PAB：∠PAB = θ，∠PBA = ∠ABC − θ
- △PBC：∠PBC = θ，∠PCB = ∠ACB − θ
- △PCA：∠PCA = θ，∠PAC = ∠BAC − θ

### 第 (1) 问
在 △APC 中，∠APC = π − θ − (∠BAC − θ) = π − ∠BAC，故 sin∠APC = sin∠BAC。

正弦定理：$\frac{PA}{\sin\theta} = \frac{b}{\sin\angle APC} = \frac{b}{\sin\angle BAC}$

故 $\frac{PA}{b} = \frac{\sin\theta}{\sin\angle BAC} = \frac{1/5}{3/5} = \frac{1}{3}$。

**重要推论（为第二问埋下伏笔）**：
同理在 △APB 中可得 $\frac{PB}{c} = \frac{\sin\theta}{\sin\angle ABC}$，
在 △BPC 中可得 $\frac{PC}{a} = \frac{\sin\theta}{\sin\angle ACB}$。

这三条对称等式是第二问①的关键武器。

### 第 (2) 问 ①
**目标**：证明 $\prod \sin(\angle X - \theta) = \sin^3\theta$，代入 $\theta = \pi/6$ 得 $\frac{1}{8}$。

**方法**：在每个子三角形里换个角度应用正弦定理。

在 △APC 中，另一个正弦定理式：$\frac{PC}{\sin(\angle BAC - \theta)} = \frac{b}{\sin\angle BAC}$，
反解出 $\sin(\angle BAC - \theta) = \frac{PC \sin\angle BAC}{b}$。

同理：
$\sin(\angle ABC - \theta) = \frac{PA \sin\angle ABC}{c}$（来自 △APB）
$\sin(\angle ACB - \theta) = \frac{PB \sin\angle ACB}{a}$（来自 △BPC）

三式相乘：

$$\prod \sin(\angle X - \theta) = \frac{PA}{b} \cdot \frac{PB}{c} \cdot \frac{PC}{a} \cdot \sin\angle BAC \sin\angle ABC \sin\angle ACB$$

代入第 (1) 问推论：$\frac{PA}{b}\cdot\frac{PB}{c}\cdot\frac{PC}{a} = \frac{\sin^3\theta}{\sin\angle BAC \sin\angle ABC \sin\angle ACB}$

三个内角 sine 的乘积上下抵消，得 $\prod \sin(\angle X - \theta) = \sin^3\theta$。

代入 $\theta = \pi/6$，$\sin^3(\pi/6) = (1/2)^3 = 1/8$。

### 第 (2) 问 ②
**目标**：固定 ∠BAC = π/3，求 tanθ 范围。

不能再用①的对称消元法，因为只剩一个角是定值。改用 PA 的两种表达相等：
- 从 △APC（过 (1)）：$PA = \frac{b\sin\theta}{\sin\angle BAC}$
- 从 △APB 另一侧：$PA = \frac{c\sin(\angle ABC - \theta)}{\sin\angle ABC}$

令两式相等，记 $A = \angle BAC$, $B = \angle ABC$, $C = \angle ACB$，由正弦定理 $\frac{c}{b} = \frac{\sin C}{\sin B}$：

$\sin A \sin C \sin(B - \theta) = \sin^2 B \sin\theta$

展开 $\sin(B - \theta)$ 并整理，两边除 sinθ：

$\cot\theta = \frac{\sin^2 B + \sin A \sin C \cos B}{\sin A \sin B \sin C} = \frac{\sin B}{\sin A \sin C} + \frac{\cos B}{\sin B}$

关键化简：用 B = π − A − C 得 sinB = sin(A+C)，展开后 $\frac{\sin B}{\sin A \sin C} = \cot C + \cot A$。故：

$$\boxed{\cot\theta = \cot A + \cot B + \cot C}$$

（**布洛卡角经典公式**，值得单独板书）

代入 A = π/3，cotA = 1/√3。B + C = 2π/3，令 C = 2π/3 − B，则：

$\cot\theta = \frac{1}{\sqrt 3} + \cot B + \cot(2\pi/3 - B)$

记 $f(B) = \cot B + \cot(2\pi/3 - B)$。通分后分子 $= \sin(2\pi/3) = \frac{\sqrt 3}{2}$，分母 $= \sin B \sin(2\pi/3 - B)$ 用积化和差 $= \frac{1}{2}[\cos(2B - 2\pi/3) + \frac{1}{2}]$。

故 $f(B) = \frac{\sqrt 3}{\cos(2B - 2\pi/3) + \frac{1}{2}}$。

**锐角约束**：B, C ∈ (π/6, π/2)，故 2B − 2π/3 ∈ (−π/3, π/3)，cos ∈ (1/2, 1]。分母 ∈ (1, 3/2]，f(B) ∈ [2√3/3, √3)。

$\cot\theta \in [\frac{1}{\sqrt 3} + \frac{2\sqrt 3}{3}, \frac{1}{\sqrt 3} + \sqrt 3) = [\sqrt 3, \frac{4\sqrt 3}{3})$

取倒数（方向翻转）：$\tan\theta \in (\frac{3}{4\sqrt 3}, \frac{1}{\sqrt 3}] = (\frac{\sqrt 3}{4}, \frac{\sqrt 3}{3}]$。

### 备选方法

第 (2) ② 也可换元 $t = \cot B$，把 $f(B)$ 写成 t 的对勾函数 $\frac{\sqrt{3}(t^2+1)}{\sqrt{3}t + 1}$，化简后用对勾函数单调性分析。这是答案细则的做法，计算稍繁，但更直观。推荐给学有余力的学生，讲解视频用三角化简法更优美。

## 四、前置知识清单

1. **正弦定理**
   - 本题用法：三个子三角形里反复用。核心是 $\frac{\text{边}}{\sin(\text{对角})} = 2R$ 这个比例。
   - 熟练程度：必须条件反射。尤其要会"换个角度"应用（PA 对 ∠PCA 还是对 ∠PAC，给出两条不同等式）。

2. **三角形内角和 + 诱导公式 sin(π − x) = sinx**
   - 本题用法：算 ∠APC 时立刻用。
   - 熟练程度：必须记牢。

3. **和差角公式 / 积化和差 / 二倍角公式**
   - 本题用法：第 (2) ② 化简 f(B) 时，sine 和差展开、分母积化和差、分析区间用 cos 的二倍角变形。
   - 熟练程度：必须熟练。

4. **锐角三角形的角度约束**
   - 本题用法：第 (2) ② 定范围。每个角 < π/2，配合内角和挤出每个角的开区间。
   - 熟练程度：会推导，不必死记。

5. **cot 函数的性质（单调性、与 tan 的关系）**
   - 本题用法：得到 cotθ 范围后取倒数要翻转方向。
   - 熟练程度：了解即可，关键是"取倒数 → 大小反向"。

6. **cotθ = cotA + cotB + cotC 这个结论本身**
   - 本题用法：第 (2) ② 核心。
   - 熟练程度：不需要背，题中推出。但推出后要作为"板书金句"记下来。

## 五、学生卡点地图

### 卡点 1：题目定义读不懂，三个角等式没感觉
- **位置**：读题阶段
- **原因**：∠PAB = ∠PBC = ∠PCA = θ 三个角看起来对称但学生抓不住共同点——它们是"从三角形每个顶点出发，旋转 θ 指向对边另一端"的结构。
- **破解**：画图 + 明确指出"P 把三角形切成三个子三角形，每个子三角形里有一个 θ"，然后逐一列出三组角度分布。

### 卡点 2：第 (1) 问算 ∠APC 时的角化简
- **位置**：∠APC = π − θ − (∠BAC − θ) 这一步
- **原因**：学生看到两个 θ 可能不敢相减，或者不知道从三角形内角和出发算第三个角。
- **破解**：强调"三个角加起来是 π"，机械代入就行。两个 θ 一正一负刚好抵消是"数学的馈赠"，但逻辑上没那么玄。

### 卡点 3：第 (2) ① 看到三式乘积不知道从哪里下手
- **位置**：问 ① 开始
- **原因**：
  1. 学生不熟悉"对称结构 → 三式相乘消元"这个思维模式；
  2. 从 △APC 的一条边到"把 sine(X − θ) 表达出来"需要"换个角度用正弦定理"的巧妙操作，学生往往只会用一种应用方式。
- **破解**：
  - 先引导"一个子三角形里我们已经用过正弦定理求 PA，现在换个对象，把目标放在 sin(∠BAC − θ) 上，看它能否用子三角形里的量表达"
  - 得到第一条后说："观察对称性，另外两个 sin(…−θ) 一定有类似的式子，同理可得"
  - 「样板台词：遇到三个对称的式子相乘，一定要想到——对称的部分可能会两两抵消。」

### 卡点 4：第 (2) ② 固定一个角后，学生不知道对称性没了该怎么办
- **位置**：问 ② 开始
- **原因**：
  1. 学生习惯套用 ① 的方法，想再对称消元，但只固定一个角 A，B、C 还在变，对称性破坏；
  2. 不知道"一个等式 + 两个未知"这种不对称场合怎么化归到单变量。
- **破解**：
  - 强调"条件变了，方法要变。对称消元不行了，我们退一步用一个等式 + 约束（A + B + C = π）来减元"
  - 引导"PA 在两个不同子三角形里都能算，令两式相等，把 θ 和角度关系写出来"
  - 推出 cot 和公式后，用 B 替代 C，变成 B 的单变量问题

### 卡点 5：第 (2) ② cot 和公式的推导过程中的关键化简
- **位置**：从 $\frac{\sin^2 B + \sin A\sin C \cos B}{\sin A \sin B \sin C}$ 到 $\cot A + \cot B + \cot C$
- **原因**：学生看到 sin²B 的分子不知道能拆成什么。
- **破解**：
  - 关键拆分：$\frac{\sin^2 B}{\sin A \sin B \sin C} = \frac{\sin B}{\sin A \sin C}$，再用 sinB = sin(A+C) 展开
  - sin(A+C) = sinAcosC + cosAsinC，除以 sinAsinC 得 cotC + cotA
  - 剩下的 $\frac{\cos B}{\sin B} = \cot B$

### 卡点 6：第 (2) ② 取范围时锐角三角形的边界
- **位置**：求 B 的范围
- **原因**：B, C 都要是锐角，学生可能只想到 "B < π/2"，忘了 C = 2π/3 − B < π/2 也要一起限制，得 B > π/6。
- **破解**：明确"每个角都要 < π/2"，配合内角和挤出 B ∈ (π/6, π/2)。

### 卡点 7：第 (2) ② 取倒数时开闭区间反转
- **位置**：cotθ ∈ [√3, 4√3/3) → tanθ ∈ (3/(4√3), 1/√3]
- **原因**：学生忘了 cot 和 tan 互为倒数，取倒数时大小关系翻转（对正值），开闭也翻转。
- **破解**：提醒"正数取倒数，大小反向，闭端对闭端、开端对开端"。

## 六、关键跳跃点（Why 慢镜头）

### 跳跃 1：第 (2) ① 从单个三角形到三式相乘
- **表象**：在每个子三角形里用正弦定理推出 sin(X − θ) 的表达式，然后三式相乘
- **Why**：布洛卡点的定义是**循环对称**的——A、B、C 三个顶点在定义里完全对等，只是角色循环替换。这种对称性暗示"三个相关量相乘"会让非对称的部分以某种方式组合出漂亮结果。事实上这里是对称部分上下抵消。
- **迁移价值**：**看到三元循环对称结构、目标含三元对称的某种乘积 → 尝试三式相乘**。经典例子还有：三角形内切圆 r = (s-a)(s-b)(s-c)/s 之类的结构。
- **样板台词**：「为什么要三式相乘？因为布洛卡点对 A、B、C 三个顶点是循环对称的，每条等式对应一个顶点，三条等式相乘后对称的部分会互相抵消，剩下一个纯粹的不变量。这是对称结构最常见的用法。」

### 跳跃 2：第 (2) ② cotθ 和公式的"出现"
- **表象**：PA 两种表达相等，几步化简后居然得出 $\cot\theta = \cot A + \cot B + \cot C$
- **Why**：这不是凑出来的，是布洛卡角的定义性质。几何上可以理解为：布洛卡角的 cot 值衡量了 P 到三顶点的"投影效率"，这个效率是三顶点分别贡献的 cot 值的算术和。推导上，关键是分子 sin²B + sinA sinC cosB 用 sinB = sin(A+C) 可以拆成完美的对称形式。
- **迁移价值**：**看到形如"多个 sin 比值 + 一个角度约束"的等式 → 尝试向 cot 和 / tan 和式靠近**。因为 cot 对加法友好（B = A + C 时 cot 有加法定理）。
- **样板台词**：「这个公式叫布洛卡角定理，是这道题的灵魂。大家记住：布洛卡角的余切，等于三个内角余切之和。这是经典结论，考场上推出来可以直接放大板书——它是这道题所有后续计算的发动机。」

### 跳跃 3：第 (2) ② 把 cot 和 sinsin 搭桥
- **表象**：$\frac{\sin^2 B + \sin A \sin C \cos B}{\sin A \sin B \sin C}$ 拆成 $\cot A + \cot B + \cot C$ 的过程
- **Why**：数学上这是经典的"sin(A+C) 展开 + 除以 sinAsinC 凑 cot"技巧。发现这个拆法的动机是——看到分子有 sin²B 和 sinAsinCcosB 两项，后者刚好是 sin(A+C)cosB 的一半结构，联想到 sinB = sin(A+C)。
- **迁移价值**：sin²B 出现时，若有对称约束 A+B+C=π，立刻想到 sinB = sin(A+C)，可以把 sin²B 变成对称形式。
- **样板台词**：「这一步化简有点巧，关键是看到分子 sin 平方 B 可以用 sinB = sin(A+C) 展开。一旦展开，你会惊喜地发现分子分母都对称了。这种'利用内角和把单角拆成两角'的技巧，是三角恒等变换的核心套路。」

## 七、易错点

1. **角度分布写反**：∠PBA 要写成 ∠ABC − θ，不要写成 θ + 某（学生容易加反）。**位置**：建立角度分布时。**避免**：画图，标清楚 BP 把 ∠ABC 切成哪两半。

2. **第 (1) 问推广的三条公式下标配错**：PA/b（PA 对 A 所在边的对边 b），不要写成 PA/c。**位置**：从第 (1) 问推广到三个公式时。**避免**：记清楚"P 到某顶点的距离 / 该顶点所在角的对边 = sinθ / sine 该角"。

3. **第 (2) ① 三式相乘时 PA、PB、PC 的配对**：三条 sin(X−θ) 的表达里，PA 对 sin(∠ABC−θ)、PB 对 sin(∠ACB−θ)、PC 对 sin(∠BAC−θ)——**错位配对**是学生最容易犯的错。**位置**：三式相乘时。**避免**：写下每条等式出自哪个子三角形，在草稿上标清楚。

4. **第 (2) ② B 的范围搞错**：只写 B < π/2，忘了 C = 2π/3 − B < π/2 给出的 B > π/6。**位置**：锐角约束分析时。**避免**：两个约束都写出来，取交集。

5. **第 (2) ② 开闭端反转**：cos 在 (−π/3, π/3) 上，B = 0（即 2B − 2π/3 = 0）时 cos 取到 1（闭），端点 ±π/3 时 cos 等于 1/2（开）。注意端点能否达到。

6. **取倒数时丢开闭**：cotθ 左端 √3 是闭的，对应 tanθ 右端 1/√3 要是闭的。学生容易全写开或全写闭。

## 八、核心心法

### 心法 1：面对陌生概念，先观察内部结构
布洛卡点、费马点这类"情景题"的共同套路——**题目给你一个陌生概念，让你在合适的题目里用上**。关键是观察概念的**内部几何结构**——P 在三角形内就会形成三个子三角形、P 到三顶点的三个距离、三个"张角"。把陌生概念拆成熟悉的几何实体，再套熟悉的工具（正弦定理、余弦定理、向量）。

**样板台词**：「拿到一个没见过的概念，不要被定义吓住。看它的几何结构，把它拆成你认识的东西：三角形、圆、距离、角。拆完你会发现——其实还是那些老工具。」

### 心法 2：对称结构的威力——三式相乘消元
一道题里如果有循环对称的三个（或多个）对象，每个对象可以单独列等式，那么**三式相乘往往让对称部分抵消，得到简洁的不变量**。第 (2) ① 的 $\prod\sin(X-\theta) = \sin^3\theta$ 就是这个套路的典型。

**迁移场景**：三角形三顶点对称结构、三元对称不等式、圆内接多边形各对边对称等。

**样板台词**：「看到三个对称的量，不要分开算。它们一起相乘，对称会自己消元。这是高等数学里群论的直觉：对称即不变量。」

### 心法 3：不对称问题的化归——把它变成单变量
当对称性被破坏（第 (2) ② 固定一个角），无法用对称消元法时，**用一个等式加约束条件减元**，把问题化成单变量函数求范围/最值。具体操作：PA 的两种表达相等给一个等式，配合 A+B+C=π，最终可以把 cotθ 表达成单变量 B 的函数。

**样板台词**：「对称性是偷懒的捷径。一旦对称没了，就得诚实地减元——用等式和约束把所有未知变成一个未知，剩下的就是单变量分析。减元是数学的诚实劳动。」

## 九、讲解推荐路径

1. **读题 + 画图**
   - 把布洛卡点定义讲清楚
   - 画出 △ABC 和 P，三个 θ 分别是从 A、B、C 指向的角度
   - 强调"三个子三角形 + 公共 θ"这个关键结构

2. **角度分布铺垫**
   - 列出每个子三角形的所有角
   - 这一步是所有后续推导的基础，不能省

3. **第 (1) 问 · 正弦定理入门**
   - 在 △APC 里走一遍，得 PA/b = 1/3
   - **完成后立即做"推广"**：三条对称式列出来，明确告诉学生"这三条等下要用"

4. **过渡 + 第 (2) ① · 对称消元**
   - 强调"同一道题的不同小问之间，第一问的结论往往是第二问的钥匙"
   - 从 PA 的一种表达切入，推出 sin(∠BAC − θ) 的对称式
   - 启发"三式相乘"思路，强调对称性的威力
   - 核心顿悟：$\prod = \sin^3\theta$——这是本题最美的时刻，应当作为 wow 演出
   - 代入 θ = π/6，答案 1/8

5. **过渡 + 第 (2) ② · 对称性破坏后的单变量化**
   - 明确说"条件变了，对称没了，方法必须变"
   - PA 两种表达相等 → 化简得 cot 和公式
   - cot 和公式要专门板书放大——这是本题的"核心公式"，值得特殊演出
   - 代入 A = π/3，变成 B 的单变量函数
   - 化简 f(B)，用积化和差和 cos 区间分析
   - 求 tanθ 范围，强调开闭端反转

6. **终章 · 三层启发**
   - 面对陌生概念要观察内部结构
   - 对称结构三式相乘的威力
   - 不对称问题的单变量化归
   - 这三层启发可以作为 map / summary 布局的内容

## 十、备注

- **几何图必画**：三个子三角形的角度分布是本题基础，建议在读题或角度分布铺垫时画出简图，清晰标注每个 θ 和 ∠ABC − θ 等角。
- **两个"金句板书"**：
  1. $\prod\sin(\angle X − \theta) = \sin^3\theta$（第 (2) ① 顿悟）
  2. $\cot\theta = \cot A + \cot B + \cot C$（第 (2) ② 核心公式，布洛卡角定理）
  这两条值得用特殊演出（放大、特写、停顿）凸显。
- **本题教学价值超过分值本身**——即使学生这道题做不出，听完讲解也能带走"对称消元""单变量化归""陌生概念拆结构"三个可迁移思维。Pipeline 2 讲的时候应当把这三条心法作为**终章升华**，而不只是总结。
