# 备课笔记 · 襄阳四中期中 Q8 · 费马点与向量最值

## 一、题目

17 世纪法国数学家费马曾提出：在三角形所在平面内，求一点，使它到三个顶点的距离之和最小。现已证明：若 $\triangle ABC$ 三个内角均小于 $120°$，则当点 $P$ 满足 $\angle APB = \angle BPC = \angle CPA = 120°$ 时，$P$ 到三顶点的距离之和最小，点 $P$ 被称为**费马点**。

已知 $\vec{x}$ 为平面内任意一个向量，$\vec{a}$ 和 $\vec{b}$ 是平面内两个互相垂直的向量，且 $|\vec{a}| = 2$，$|\vec{b}| = 3$，则 $|\vec{x} - \vec{a}| + |\vec{x} + \vec{a}| + |\vec{x} - \vec{b}|$ 的最小值是（  ）

A. $3 + 2\sqrt{3}$ 　 B. $3 - 2\sqrt{3}$ 　 C. $2\sqrt{3} + 2$ 　 D. $2\sqrt{3} - 2$

## 二、题目定位

- **题型**：选择题压轴·情景题·向量几何化
- **核心考点**：向量模的几何意义、费马点概念应用、对称性降维、三角函数求交点
- **难度**：★★★★☆
- **分值权重**：5 分（单选压轴）

## 三、完整解法（专家版）

### 第一步：几何化
设原点 $O$，$\vec{OP} = \vec{x}$，$\vec{OA} = \vec{a}$，$\vec{OA'} = -\vec{a}$，$\vec{OB} = \vec{b}$。

则：
- $|\vec{x} - \vec{a}| = |PA|$
- $|\vec{x} + \vec{a}| = |\vec{x} - (-\vec{a})| = |PA'|$
- $|\vec{x} - \vec{b}| = |PB|$

**关键翻译**：目标 = $|PA| + |PA'| + |PB|$，即 $P$ 到 $A, A', B$ 三点距离之和。这正是 $\triangle AA'B$ 的费马点问题。

### 第二步：建系 + 验证条件
$\vec{a} \perp \vec{b}$，以 $\vec{a}$ 方向为 $x$ 轴、$\vec{b}$ 方向为 $y$ 轴：$A(2, 0)$，$A'(-2, 0)$，$B(0, 3)$。

三角形 $AA'B$ 是等腰三角形（底 $|AA'| = 4$，腰 $|AB| = |A'B| = \sqrt{13}$）。

**验证三内角 $< 120°$**：底角 $\tan\angle A = 3/2 \approx 56°$，顶角 $\approx 68°$，都 $< 120°$。费马点存在。

### 第三步：用对称性降维求费马点
等腰三角形关于 $y$ 轴对称，费马点必在对称轴上。设 $P(0, y)$。

用 $\angle APA' = 120°$ 定 $y$：$\vec{PA} = (2, -y)$，$\vec{PA'} = (-2, -y)$。

$\cos 120° = \frac{\vec{PA}\cdot\vec{PA'}}{|\vec{PA}||\vec{PA'}|} = \frac{-4 + y^2}{4 + y^2} = -\frac{1}{2}$

交叉相乘解得 $3y^2 = 4$，$y = \frac{2\sqrt{3}}{3}$。

### 第四步：算三距离和
$|PA| = |PA'| = \sqrt{4 + y^2} = \sqrt{16/3} = \frac{4\sqrt{3}}{3}$

$|PB| = 3 - y = 3 - \frac{2\sqrt{3}}{3}$

$|PA| + |PA'| + |PB| = \frac{8\sqrt{3}}{3} + 3 - \frac{2\sqrt{3}}{3} = 2\sqrt{3} + 3$

选 A。

### 备选方法
更正统的做法是用费马点位置的代数公式（Torricelli 点坐标），但对高中生来说太复杂。利用等腰对称性是最经济的路子。

## 四、前置知识清单

1. **向量模的几何意义**：$|\vec{x} - \vec{a}|$ 是 $\vec{x}$ 和 $\vec{a}$ 对应点之间的距离
   - 本题用法：整道题的**破题钥匙**
   - 熟练程度：必须条件反射

2. **向量的坐标化**：给定两个不共线向量作基底，可建立直角坐标系
   - 本题用法：$\vec{a}\perp\vec{b}$ 直接当成坐标轴
   - 熟练程度：必须

3. **费马点概念**（题目给出）
   - 本题用法：识别问题并使用
   - 熟练程度：题目给就不要求记

4. **向量夹角公式 $\cos\theta = \frac{\vec{u}\cdot\vec{v}}{|\vec{u}||\vec{v}|}$**
   - 本题用法：利用 $\angle APA' = 120°$ 定点 $P$ 的位置
   - 熟练程度：必须熟练

5. **对称性降维的思维**
   - 本题用法：等腰三角形的费马点在对称轴上，把二维问题降到一维
   - 熟练程度：理解即可，考试时能主动想到最好

## 五、学生卡点地图

### 卡点 1：看完题不知道费马点和向量式有什么关系
- **位置**：读题后
- **原因**：题目给了一大段费马点概念，又抛出一个三个向量模相加求最值的式子，学生不知道**费马点怎么用**
- **破解**：
  - 强调"这是典型的情景题套路——给你一个陌生概念，让你在合适的题目里用上它"
  - 引导学生观察目标式的结构："$|\vec{x} - \vec{a}| + |\vec{x} + \vec{a}| + |\vec{x} - \vec{b}|$——三个模相加，这种结构是信号"
  - 「样板台词：情景题的关键是——**把陌生概念翻译成熟悉结构**。这里三个模相加，翻译成三个距离相加，正好是费马点。」

### 卡点 2：$|\vec{x} + \vec{a}|$ 对应哪个点
- **位置**：几何化步骤
- **原因**：学生熟悉 $|\vec{x} - \vec{a}| = |PA|$，但遇到 $|\vec{x} + \vec{a}|$ 容易懵
- **破解**：明确改写 $\vec{x} + \vec{a} = \vec{x} - (-\vec{a})$，引入辅助点 $A' = -\vec{a}$ 的终点。这个**换个符号看**的技巧在向量题里反复用

### 卡点 3：找费马点时不知道从哪里入手
- **位置**：第三步
- **原因**：费马点一般位置是非对称三角形的定位题，学生没法直接写出坐标
- **破解**：
  - **利用对称性**：指出 $\triangle AA'B$ 是等腰的（对称轴是 $y$ 轴）
  - 由对称，费马点必在对称轴上，这直接把"二维找点"降到"一维定 $y$"
  - 「样板台词：等腰三角形的费马点在对称轴上。这不是巧合——整个图形对称，最小值的位置也要对称，否则它的镜像也是最小点，矛盾。」

### 卡点 4：用夹角 120° 定 $y$ 的列式
- **位置**：$\cos 120° = \frac{\vec{PA}\cdot\vec{PA'}}{|\vec{PA}||\vec{PA'}|}$
- **原因**：学生可能选择其他张角（$\angle APB$ 或 $\angle A'PB$）来列方程，但这些要用到 $\arctan$ 难算
- **破解**：引导选**对称的那对张角** $\angle APA'$——因为由对称性，$\vec{PA}$ 和 $\vec{PA'}$ 关于 $y$ 轴对称，写出来是 $(2, -y)$ 和 $(-2, -y)$，点积和模都非常好算

## 六、关键跳跃点（Why 慢镜头）

### 跳跃 1：向量模 → 点距（几何化）
- **表象**：$|\vec{x} - \vec{a}|$ 突然被写成 $|PA|$
- **Why**：向量的终点（设起点固定在原点）可以看作点。$\vec{x} - \vec{a}$ 的模就是 $\vec{x}$ 终点到 $\vec{a}$ 终点的距离。**这是向量几何化的第一招**，也是最重要的一招。
- **迁移价值**：**看到向量模相加（尤其是多个）求最值 → 第一反应几何化**。这是向量最值题的"十大武器"之首。
- **样板台词**：「向量模不要只当数字处理。每个模都是两点之间的距离，模之和是一条'折线的总长度'——一旦翻译成几何，所有工具都能用上：三角不等式、费马点、共线、对称等等。」

### 跳跃 2：对称性降维（二维 → 一维）
- **表象**：设 $P(0, y)$，把未知从两个降到一个
- **Why**：等腰三角形的对称轴两侧几何完全镜像，任何"到三个顶点距离和"的极值点必然在对称轴上（否则镜像点也是极值点，唯一性矛盾）
- **迁移价值**：**遇到对称结构 + 极值问题 → 极值点在对称轴上**。解析几何、向量最值、立体几何里反复用。
- **样板台词**：「对称性不光是画图漂亮。它是**可以减少未知数**的工具——有对称轴，就把未知搬到对称轴上，二维一下变一维。这是数学里最值问题的省力大招。」

## 七、易错点

1. **$|\vec{x} + \vec{a}|$ 翻译错**
   - 位置：几何化时
   - 原因：不把 $+\vec{a}$ 当作 $-(-\vec{a})$，直接配点失败
   - 避免：统一写成 $|\vec{x} - (\pm\vec{a})|$ 格式

2. **建系方向**
   - 位置：$\vec{a}, \vec{b}$ 垂直时建系
   - 原因：$\vec{a}$ 当 $y$ 轴 / $\vec{b}$ 当 $x$ 轴也没错，但会把后面的计算搞乱
   - 避免：按题目习惯，先给 $\vec{a}$ 分配 $x$ 轴

3. **费马点位置条件判断遗漏**
   - 位置：第二步
   - 原因：学生可能忘记验证"三内角 $< 120°$"
   - 避免：每次用费马点之前，必须算一下底角或估个数

4. **夹角公式符号错**
   - 位置：$\cos 120°$ 代入
   - 原因：$\cos 120° = -1/2$，学生可能写成 $1/2$
   - 避免：120° 是钝角，余弦必为负

## 八、核心心法

### 心法 1：向量几何化是最大的武器

**看到向量模（尤其是多个模相加），一律几何化——把向量理解为点的位置，模理解为距离。**

几何化之后：
- 三个距离相加 → 费马点 / 三角不等式
- 两个距离之和/差 → 椭圆/双曲线
- 距离之比 → 阿波罗尼奥斯圆

代数的向量式一旦变成几何问题，高中所有几何工具都接上来了。

**样板台词**：「向量题不要硬算。模 → 距离，向量 → 点。一旦几何化，原来那些吓人的绝对值符号都变成线段，工具库一下打开。」

### 心法 2：对称性是"减元"的钥匙

遇到对称的结构（等腰、中心对称、轴对称），求最值或定点时，**极值点必落在对称元素上**——对称轴、对称中心、不动点。这能把问题的维度直接减一。

**样板台词**：「对称是数学里的免费午餐。看到对称，自动把未知搬到对称元素上——这不是经验法则，是逻辑定理：对称图形的极值点必须对称。」

### 心法 3：情景题的翻译原则

数学考试里的"情景题"（给一个陌生概念，用在具体题里）的通用套路：**把陌生概念的定义拆成几何或代数结构，再把题目条件也翻译成同样的结构，两者一对，就能套用概念**。

费马点的"三张角 120°"、布洛卡点的"三等角 θ"、阿波罗尼奥斯圆的"距离比"——每个陌生概念都有一个**结构签名**，识别出来就破题一半。

## 九、讲解推荐路径

1. **读题 + 概念引入**
   - 费马点是什么（题目已给）
   - 把目标式抛出来，问学生：**这和费马点有什么关系？**

2. **几何化（核心跳跃 1）**
   - $|\vec{x} - \vec{a}| = |PA|$
   - $|\vec{x} + \vec{a}| = |PA'|$（换符号看）
   - $|\vec{x} - \vec{b}| = |PB|$
   - 目标式就是 $|PA| + |PA'| + |PB|$——识别出费马点

3. **建系 + 画图**
   - $\vec{a}$ 当 $x$ 轴、$\vec{b}$ 当 $y$ 轴
   - 三点坐标：$A(2,0), A'(-2,0), B(0,3)$
   - 画简图：等腰三角形
   - 验证内角 $< 120°$

4. **对称性降维（核心跳跃 2）**
   - 等腰 → 费马点在 $y$ 轴上
   - 设 $P(0, y)$，只有一个未知

5. **用 $\angle APA' = 120°$ 求 $y$**
   - 为什么选这个张角（对称最好算）
   - 列夹角余弦方程
   - 解 $y = 2\sqrt{3}/3$

6. **算三距离和，得答案 $3 + 2\sqrt{3}$**

7. **终章 · 三层心法**
   - 向量几何化是最大武器
   - 对称性是减元钥匙
   - 情景题的翻译原则

## 十、备注

- **画图必做**。等腰三角形的直观图对理解"对称轴 = $y$ 轴"和"费马点在轴上"至关重要。
- **两层核心跳跃都要给特写**：
  - 几何化：让学生看见"模 → 距离"的翻译瞬间
  - 对称性：让学生顿悟"为什么设 $P(0, y)$ 就够了"
- 这道题是**情景题的典型**——学完之后学生应该能迁移到其他"给陌生概念 + 抽象代数式"的类似题型。终章的三层心法要强调这种迁移。
- 选项里 B 和 D 是正负错误的干扰项（$3 - 2\sqrt{3}$ 是负数，不可能是距离和）——可以作为提醒学生"选项为负先排除"的隐形教学点。
