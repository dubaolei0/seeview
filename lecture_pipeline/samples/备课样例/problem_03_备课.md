# 备课笔记 · 襄阳期中 Q3 · 向量平行的充要条件

## 一、题目

设 $\vec{a}, \vec{b}$ 是非零向量，"$|\vec{a} + \vec{b}| = |\vec{a}| + |\vec{b}|$"是"$\vec{a} \parallel \vec{b}$"的（  ）

A．充分不必要条件　B．必要不充分条件　C．充要条件　D．既不充分也不必要条件

## 二、题目定位

- **题型**：选择题·充要条件·向量模
- **核心考点**：向量模的三角不等式、向量平行的等价条件、充分/必要条件判断
- **难度**：★★★☆☆
- **分值权重**：5 分
- **答案**：A（充分不必要条件）

## 三、完整解法（专家版）

### 条件梳理
设命题 P：$|\vec{a} + \vec{b}| = |\vec{a}| + |\vec{b}|$
设命题 Q：$\vec{a} \parallel \vec{b}$

判断 P 与 Q 的充分/必要关系。

### P ⇒ Q 是否成立（P 是 Q 的充分条件？）

由向量模的三角不等式：$|\vec{a} + \vec{b}| \leq |\vec{a}| + |\vec{b}|$，等号成立 $\Leftrightarrow$ $\vec{a}$ 与 $\vec{b}$ **同向**（即方向相同）。

"同向"是"平行"的真子集——$\vec{a} \parallel \vec{b}$ 包括**同向和反向**两种情况。

若 $|\vec{a} + \vec{b}| = |\vec{a}| + |\vec{b}|$，则 $\vec{a}$ 与 $\vec{b}$ 同向，从而 $\vec{a} \parallel \vec{b}$。**P ⇒ Q 成立**。

### Q ⇒ P 是否成立（P 是 Q 的必要条件？）

$\vec{a} \parallel \vec{b}$ 包括两种情况：
1. $\vec{a}$ 与 $\vec{b}$ 同向：$|\vec{a} + \vec{b}| = |\vec{a}| + |\vec{b}|$ ✓
2. $\vec{a}$ 与 $\vec{b}$ 反向：$\vec{a} + \vec{b}$ 的模 $= \big||\vec{a}| - |\vec{b}|\big| \neq |\vec{a}| + |\vec{b}|$（只要 $|\vec{a}| \neq |\vec{b}|$ 就不等；若 $|\vec{a}| = |\vec{b}|$ 则 $|\vec{a} + \vec{b}| = 0 \neq |\vec{a}| + |\vec{b}|$）✗

所以 $\vec{a} \parallel \vec{b}$ 不能推出 $|\vec{a} + \vec{b}| = |\vec{a}| + |\vec{b}|$（反向时不成立）。**Q ⇒ P 不成立**。

### 结论

P 是 Q 的**充分不必要条件**，答案 A。

## 四、前置知识清单

1. **充分/必要条件定义**：
   - P 是 Q 的充分条件 $\Leftrightarrow$ P ⇒ Q（P 能推出 Q）
   - P 是 Q 的必要条件 $\Leftrightarrow$ Q ⇒ P（Q 能推出 P）
   - 本题用法：两个方向分别验证
   - 熟练程度：条件反射级，不能靠模糊印象

2. **向量平行（共线）的定义**：$\vec{a} \parallel \vec{b}$ 包括**同向**和**反向**两种情况（高中教材规定：平行/共线包含两种方向）
   - 本题用法：关键——学生常以为平行只有同向，这是本题的陷阱
   - 熟练程度：必须明确

3. **向量模的三角不等式**：$|\vec{a} + \vec{b}| \leq |\vec{a}| + |\vec{b}|$，等号成立 $\Leftrightarrow$ $\vec{a}$ 与 $\vec{b}$ **同向**（方向相同且非零）
   - 本题用法：P 条件的几何含义就是这个等号
   - 熟练程度：必须，且要记住等号条件是"同向"不是"平行"

4. **反向向量的模**：$\vec{a}$ 与 $\vec{b}$ 反向时，$|\vec{a} + \vec{b}| = \big||\vec{a}| - |\vec{b}|\big|$
   - 本题用法：构造 Q 不能推出 P 的反例
   - 熟练程度：需要理解

5. **举反例法**：证明"A 不能推出 B"，只需给出一个 A 成立但 B 不成立的例子
   - 本题用法：Q 不能推出 P，举 $\vec{a}$ 与 $\vec{b}$ 反向的例子即可
   - 熟练程度：必须

## 五、学生卡点地图

### 卡点 1：把"平行"等同于"同向"
- **位置**：判断 Q ⇒ P 时
- **原因**：高中生容易把向量平行只想到同向，忽略反向情况
- **破解**：明确高中教材中 $\vec{a} \parallel \vec{b}$ **含反向**。考试中说平行，就要同时考虑同向和反向两种情况

### 卡点 2：充分/必要方向搞反
- **位置**：最终得出结论时
- **原因**：充分/必要概念不清，P 能推 Q 搞不清是 P 是 Q 的什么条件
- **破解**：背口诀「P 能推 Q，P 是 Q 的充分条件」，写成 P⇒Q 的箭头，充分方向跟箭头方向一致

### 卡点 3：三角不等式等号条件背错
- **位置**：判断 P ⇒ Q 时
- **原因**：学生以为等号成立是"平行"（包括反向），实际上只有"同向"
- **破解**：从几何理解——向量加法平行四边形法则，只有两个向量同向时，合向量的模才等于两个模之和；反向时合向量模等于差

## 六、关键跳跃点（Why 慢镜头）

### 跳跃 1：三角不等式等号条件是"同向"而非"平行"
- **表象**：等号成立 $\Leftrightarrow$ $\vec{a}$ 与 $\vec{b}$ 同向
- **Why**：向量加法平行四边形法则——$\vec{a} + \vec{b}$ 是对角线，只有两边共线（同向）时对角线最长等于两边之和；反向时对角线等于差
- **迁移价值**：三角不等式等号条件=向量同向，不是平行。这是高频陷阱

### 跳跃 2：平行包含反向，反向是推翻 P⇒Q 逆命题的反例来源
- **表象**：直接取 $\vec{a}$ 与 $\vec{b}$ 反向作为反例
- **Why**：想反驳"Q ⇒ P"，只需一个 Q 真 P 假的例子。Q=平行包含反向，反向时 P 不成立，一个反例搞定
- **迁移价值**：充要条件题的标准操作——两个方向都验证，一个方向找反例

## 七、易错点

1. **向量平行含反向**：最核心易错，只要平行=同向，选 C 就错了
2. **充分/必要方向混淆**：P⇒Q 说明 P 是充分条件，和 P 是必要条件弄反
3. **反例举不够具体**：只说"反向不满足"但不给具体数值，容易丢分。建议举：$\vec{a} = (1,0)$，$\vec{b} = (-1,0)$，则平行，但 $|\vec{a}+\vec{b}| = 0 \neq 2 = |\vec{a}|+|\vec{b}|$

## 八、核心心法

**充要条件题的双向验证标准操作**：
1. 验证 P⇒Q：根据 P 的定义，推出 Q 的结论
2. 验证 Q⇒P（的逆）：找到一个 Q 成立但 P 不成立的反例

**本题的核心分辨**：$|\vec{a}+\vec{b}|=|\vec{a}|+|\vec{b}|$ 对应"同向"，而 $\vec{a}\parallel\vec{b}$ 对应"同向或反向"——**同向是平行的真子集**，所以同向⇒平行（充分），平行不能推同向（不必要）。

## 九、讲解推荐路径

1. 设 P = 模等式，Q = 平行，明确要验证两个方向
2. P⇒Q：三角不等式等号条件是同向，同向⇒平行，成立
3. Q⇒P：举反向反例（具体数值），不成立
4. 结论：充分不必要，选 A
5. 心法：向量平行包含反向，是本题关键；充要条件双向验证标准流程
