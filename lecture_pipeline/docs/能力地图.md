> 设计稿 v2。定义新渲染器将支持哪些能力，作为 Pipeline 2 schema 设计的约束，也作为工程实现的 MVP 边界。
>
> 状态：**v2 修订版**。基于多轮对齐的讨论更新。待你最终通过后进入 schema 设计阶段。

## 设计哲学

与老渲染器 `batch_generate_write.py` 相比，v3 的核心改变不在"能不能画"，而在**画之前的抽象层**。

- 老版：每个 step 共享一张"板书画布"，靠 FadeIn/FadeOut 堆内容，所有题共用同一个画面模板
- 新版：按"**阶段**"切换主画面形态、按"**Block 语义**"决定字体/颜色/动画。AI 只写语义，不写坐标

三个核心设计决策：

**决策 1：固定四阶段 + 讲题内多 Act**
视频结构是：**读题 → 讲题 → 升华**。三个阶段切换画面形态；讲题阶段内部由多个 Act 构成（知识铺垫、推导、顿悟、对比等），Act 切换只改推导主区，顶栏和锚点常驻。

**决策 2：语义类型驱动样式**
内容是 Block，不是扁平 step。Block 有 `type`（问题陈述、知识卡、推导步、警告、顿悟公式、答案框、心法条……），type 决定字体、颜色、边框、入场动画——由 Theme 统一配置。

**决策 3：动画词汇语义化**
不是万用 Write + FadeOut。按内容类型注册动画：金句 Flash、顿悟 Scale + Pause、推导 Write、常规 FadeIn。老师讲课的圈画擦指批注连线，全用 Manim 原生能力。

## 视觉语言（基于 templates.tex）

整个视觉系统以用户提供的 `templates.tex` 为参考。**tex 文件本身不参与编译**——v3 不生成 PNG 背景图，所有装饰由 Manim 原生 Mobject 复刻。

### 调色板（从 tex 抽出）

```python
MAIN_BLUE = "#0070C0"    # 主题色，页眉、卡片标题、重要结论
BG_BLUE   = "#E5F2FA"    # 浅蓝背景，思考框填充
BG_YELLOW = "#FDF5E6"    # 浅黄背景，公式/重要结论框填充
MAIN_PINK = "#CC5577"    # 次级强调色，易错提示、练习题
EYE_WHITE = "#FAF9F4"    # 护眼白，全局背景
TEXT_DARK = "#1A1A1A"    # 正文文字
TEXT_MUTED = "#666666"   # 次要文字（如"已知"标签）
```

### 字体方案

```
默认（正文）：        ctex 宋体等价体（Manim 用 STSong 或 SimSun）
数学公式：            衬线传统（Computer Modern，manim 默认）
顶栏/标题/知识点标题：  无衬线加粗（方案1：SimHei；方案2：PingFang）
心法/总结/金句：       楷体（KaiTi）
```

### 顶栏样式（复刻 templates.tex 的 frametitle）

```
┌────────────────────────────────────────────┐
│  [mainblue 无衬线加粗 · 20-24pt]            │  ← 文字
│  ────────────────────────────────────────  │  ← 0.8pt mainblue 细线
└────────────────────────────────────────────┘
```

Manim 实现：一个 `Text` 对象（左对齐）+ 一条 `Line`（宽度 = 画面宽度 - 2×边距）组合。顶栏整体放在 y = 顶部边距 的位置，常驻。

### 卡片样式

**YellowBox（公式 / 重要结论）**
- 底色：`BG_YELLOW`
- 无边框（`boxrule=0pt`）
- 圆角 `arc=2pt` → Manim 用 `RoundedRectangle` corner_radius=0.05
- 内边距 2mm
- 头部可选带图标 `summaryicon`（Manim 用小圆 + 字母 "B"）+ 粗体蓝色标题

**BlueBox（思考 / 引导）**
- 底色：`BG_BLUE`
- 无边框、圆角 2pt
- 头部可选带图标 `thinkicon`（小圆 + 沙漏字母）

**ExerciseBox（易错提示 / 练习）**
- 底色：`EYE_WHITE`（和全局背景融合）
- 边框：1pt mainpink 虚线
- 左上有 mainpink 圆角标签（写 "警告" 或 "练习"）

MVP 实现这三种卡片，Block 类型按语义映射。

## 四阶段结构（固定骨架）

### 阶段 1：读题（= 开场）

**这一阶段 = 视频开场，没有单独的"封面阶段"**。TTS 第 0 秒开始就播 `problem.narration`，画面同步渐入题干。

**画面**：
```
┌──────────────────────────────────────────┐
│                                          │
│                                          │  没有顶栏
│        襄阳期中 · 第 6 题（大字号）         │  没有装饰
│                                          │  纯 eye_white 背景
│   [题干全文居中，中大字号]                  │
│                                          │
│                                          │
└──────────────────────────────────────────┘
```

视频第一帧 = 这张画面，即 Windows 资源管理器的缩略图。

**持续时间**：等于 `problem.narration` 音频时长 + 短暂停顿

### 阶段 2 转场：题干收、顶栏浮现、锚点浮现

读题结束后的 1-1.5 秒：
- 题目大字号缩放平移到顶栏位置
- 顶栏细线从左到右画出
- 右栏锚点卡片从右侧滑入（如有 anchors）或题干缩到顶栏下单行（如无 anchors）
- 主区清空

**两种布局分支**（关键！）

**分支 A：AI 提供了 anchors**
```
┌──────────────────────────────────────────┐
│  [顶栏：第 6 题 · 向量数量积]  ─────────     │  ← 顶栏
├──────────────────────────────┬───────────┤
│                              │ 已知       │
│                              │ $\vec a=(1,2)$  │  ← 锚点卡片
│      推导主区（空白）           │ $|\vec b|=\sqrt3$  │
│                              │ ...       │
│                              │ 求 $\vec a\cdot\vec b$ │
└──────────────────────────────┴───────────┘
主区宽度 约 70%，锚点栏 约 30%
```

**分支 B：AI 未提供 anchors（题干短）**
```
┌──────────────────────────────────────────┐
│  [顶栏：第 1 题 · 复数]    ─────────         │
│  已知 $zi = -1 + 2i$                       │  ← 题干缩成顶栏下一行
├──────────────────────────────────────────┤
│                                          │
│      推导主区（全宽 100%）                  │
│                                          │
└──────────────────────────────────────────┘
```

**分支 C：AI 未提供 anchors 且题干含图**（如 Q13 测塔高、Q17 菱形）
```
┌──────────────────────────────────────────┐
│  [顶栏]  ─────────                        │
├──────────────────────────┬───────────────┤
│                          │               │
│      推导主区             │   几何图常驻    │
│                          │               │
│                          │               │
└──────────────────────────┴───────────────┘
```

**由渲染器根据 yaml 字段自动决定使用哪个分支**：
- `problem.anchors` 非空 → 分支 A
- `problem.anchors` 空 + `problem.figure` 非空 → 分支 C
- `problem.anchors` 空 + `problem.figure` 空 → 分支 B

### 阶段 3：讲题（内部多 Act）

顶栏 + 锚点卡片 + 几何图（如有）**全程常驻**，Act 切换只改推导主区内容。

Act 类型（Pipeline 2 自由选择）：

| Act | 含义 | 典型用法 |
|---|---|---|
| `knowledge` | 知识点铺垫 | 用 YellowBox 卡片逐个呈现定理/公式 |
| `derivation` | 常规推导 | 板书式逐步展开 |
| `insight` | 关键顿悟 / wow 时刻 | 核心公式 Scale Up + Flash + Pause |
| `contrast` | 对比两种方法 | 分左右栏 |
| `verification` | 检验 / 舍解 | 带 ✓ / ✗ 标记 |
| `transition` | 纯过渡 | 空 narration，不显示内容变化 |

**Act 切换行为**（默认不清屏，温和过渡）：
- 当前推导主区内容如果满了 → 启用**滚动机制**（沿用老渲染器方案：新内容从底部压入，旧内容从顶部淡出）
- 如果 Act 内容性质变化大（比如 derivation → insight）→ 当前主区 FadeOut + 短暂空白 0.3 秒 + 新 Act 进入
- 顶栏 / 锚点 / 几何图永远不受影响

### 阶段 4：升华

**画面**：
```
┌──────────────────────────────────────────┐
│  [顶栏：第 6 题 · 向量数量积]  ─────────     │  ← 顶栏保留（品牌一致性）
├──────────────────────────────────────────┤
│                                          │
│          [心法 / 思维导图 / 方法总结]        │
│              （主区全宽）                   │
│                                          │
└──────────────────────────────────────────┘
```

**转场**：从讲题阶段进入升华时，锚点卡片 FadeOut + 推导主区 FadeOut + 新内容淡入。顶栏保留。

## 文字板书的布局抽象（关键工程问题）

> 你提到"老渲染器不会出现文字覆盖"——新渲染器要保证同样的约束。沿用老方案但升级。

### 老方案的核心机制（from `batch_generate_write.py`）

- 主区用 `minipage` 约束宽度，内容用 `\par` 换行
- 新内容从**当前光标位置**往下写
- 写满底部时**触发滚动**：最上面的 Mobject fade out，剩余 Mobject 整体上移腾位置

新渲染器继承这个机制，但封装进 `BoardRegion` 类。Pipeline 2 只写"Block 列表"，不操心光标、滚动、minipage。

### 实现思路

```python
class BoardRegion:
    """推导主区。保证任意时刻 Mobject 不重叠。"""
    def __init__(self, x, y, width, height, max_items=10):
        self.cursor_y = y
        ...
    
    def add_block(self, block: Block, scene: Scene):
        # 创建 Mobject，根据 block.type 选字体/颜色/框
        mob = self._render(block)
        mob.move_to(self._next_position())
        
        # 检查是否会溢出底部
        if self._would_overflow(mob):
            self._scroll_top_out(scene)
        
        # 播入场动画
        scene.play(block.entrance_anim(mob))
        self.items.append(mob)
        self.cursor_y -= mob.height + SPACING
```

**Pipeline 2 永远不写坐标**。所有位置由 BoardRegion 管理。

### 同理，每个区域都是一个 Region

- `HeaderRegion`（顶栏）：固定位置，只支持"设置标题文字"
- `AnchorRegion`（锚点栏）：固定位置，初始化时批量加入 anchors，讲题中不变
- `FigureRegion`（几何图栏）：固定位置，支持静态图和简单动态（动点）
- `BoardRegion`（推导主区）：动态滚动，按 Block 队列处理
- `SummaryRegion`（升华主区）：替代 Board，升华阶段启用

## Block 类型清单（MVP）

| type | 适用阶段 | 典型样式 | 入场动画 |
|---|---|---|---|
| `problem_statement` | 读题 | 默认字体，大号 | Write / FadeIn |
| `anchor_item` | 转场 / 讲题常驻 | 小号，次要色 | FadeIn from right |
| `knowledge_card` | 讲题.knowledge | YellowBox 黄底框 + 蓝色标题 | GrowFromCenter |
| `step` | 讲题.derivation | 默认字体 | Write |
| `emphasis` | 讲题.derivation 内嵌 | 红色 | Indicate |
| `warning` | 任意 | ExerciseBox 粉框 | FadeIn + Indicate |
| `answer_box` | 讲题.derivation 结尾 | YellowBox + 加粗 | GrowFromCenter |
| `wow_formula` | 讲题.insight | 超大号居中 + 金色 | Scale up + Flash |
| `takeaway` | 升华 | 楷体大号 | FadeIn + shift |
| `mindmap_node` | 升华 | 带边框节点 | Create + arrow draw |

**样式由 theme 配置**，AI 不写颜色、字号。

## 动画词汇（MVP）

| 名称 | Manim API | 场景 |
|---|---|---|
| `write` | `Write(mob)` | step, analysis |
| `fade_in` | `FadeIn(mob)` | problem_statement, anchor_item |
| `grow_from_center` | `GrowFromCenter(mob)` | knowledge_card, answer_box |
| `scale_up` | `mob.scale(0).animate.scale(1.2).scale(1.0)` | wow_formula 主视觉 |
| `flash` | `Flash(mob)` | wow_formula 配合 |
| `indicate` | `Indicate(mob)` | emphasis |
| `focus_on` | `FocusOn(point)` | 指向某处 |
| `circle_around` | `Circle around` | 圈出公式部分 |
| `fade_out` | `FadeOut(mob)` | 默认退场 |
| `shrink_to` | `mob.animate.scale(0.3).move_to(header)` | 读题结束题干缩到顶栏 |

**增强动画（MVP 含）**：
- `TransformMatchingTex`：公式演化时相同字母平移（老渲染器没有，新增）
- 动点滑动：`ValueTracker` + `always_redraw`，让几何图里的点沿曲线/线段动

## Schema 预览（Pipeline 2 的输出形态）

给一个完整示例，涵盖所有情况：

```yaml
problem:
  id: "problem_17"
  title: "襄阳期中 · 第 17 题"      # 顶栏文字
  subtitle: "菱形中的向量"           # 顶栏副标题（可选）
  statement: |                    # 读题阶段完整题干
    在菱形 $ABCD$ 中，$|\vec{AB}|=6$，
    $\angle BAD = 60°$...
  narration: "同学们，第 17 题..."   # 读题 TTS
  anchors:                         # 讲题阶段常驻（可选）
    - "$|\\vec{AB}| = 6$"
    - "$\\angle BAD = 60°$"
    - "$\\vec{BE} = \\frac{1}{2}\\vec{BC}$"
    - "$\\vec{CF} = 2\\vec{FD}$"
  figure: null                     # 题干无图

acts:
  - type: knowledge
    narration: "解向量综合题..."
    blocks:
      - type: knowledge_card
        title: "基底选择"
        body: "选不共线、模和夹角已知的两向量"
        points:
          - "本题基底：$\\vec{AB}$ 和 $\\vec{AD}$"
          - "基本量：$\\vec{m}^2 = 36$..."
  
  - type: derivation
    narration: "第一问..."
    blocks:
      - type: step
        body: "$\\vec{EF} = \\vec{EC} + \\vec{CF}$"
      - type: step
        body: "$\\vec{EC} = \\frac{1}{2}\\vec{n}$"
        emphasis: ["\\frac{1}{2}"]
      - type: step
        body: "$\\vec{CF} = -\\frac{2}{3}\\vec{m}$"
  
  - type: insight
    narration: "三式相乘..."
    blocks:
      - type: wow_formula
        formula: "\\prod \\sin(X-\\theta) = \\sin^3\\theta"
        caption: "对称消元的美妙"

summary:
  narration: "总结..."
  blocks:
    - type: takeaway
      body: "基底化是向量综合题灵魂"
    - type: takeaway
      body: "定值问题用参数法判断"
```

关键特征：
- 不写坐标、颜色、字号
- `problem` 一次定义所有读题所需（title/subtitle/statement/narration/anchors/figure）
- `acts` 是数组，每个 act 有 `type` 和 `blocks`
- `summary` 独立字段，不是 act 的一种
- narration 在 act 级别或 block 级别都可以（粒度由 AI 决定）
