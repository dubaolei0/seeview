# 图库与 AI 生题配图改造 · 进度文档

> 最后更新：2026-08-29
> 目标：基于已有 AI 生题功能，新增「参数化图库」页面与功能。图库维护数学图形模板（TikZ 代码 + 参数表），生题时大模型按题干条件选模板、填参数，后端注入参数渲染出图，替代/补充现有「模型直接写 TikZ 代码」的方式。

## 一、整体方案（已定稿）

### 双轨制绘图
- **图库轨道（命中）**：大模型输出 `fig: {id, params}` 结构化引用，后端校验参数 → 注入 `\def` → 编译出图。从根上消除转义/语法错误（模型只产 JSON 参数，不产代码）。
- **自由 TikZ 轨道（兜底）**：图库未覆盖的题型（函数图像、复合图形等）维持现有「模型写 ```tikz 代码块 + 后端 `compileTikz` 编译」路径。两条轨道二选一，同一条题干不并存。

### 存储
- `figure_library/figures/*.json`，一模板一文件；与项目无数据库、文件落盘风格一致，可进 git。
- 预览 PNG 落 `question_output/images/`（复用现有插图目录，前端经 `/seeview/local-image` 渲染）。

### 匹配机制（题干 → 图库模板）
- **生题时（时机一，主方案）**：命题即选图。提示词注入图库目录（每模板约 50~80 token），模型写题干时即按模板参数表造题，匹配准确率最高，**不产生独立匹配调用**。
- **存量题配图（时机二，增强功能，未实现）**：LLM 单轮分类 + 参数提取 + 一致性回验。可做成生题页/图库页「给这道题配图」按钮，同时作为时机一的安全网。**排在任务 4 之后。**

### 图库元数据质量（匹配率的关键）
- `desc` 必填且 ≥ 20 字，写「什么题适合用我」而非「一个三角形」。
- `tags` 收录同义说法（三棱锥/棱锥/四面体）。
- `whenNotToUse` 反例描述（可选，防硬套）。

## 二、数据模型

`seeview/src/main/java/com/yuanxuan/seeview/dto/FigureTemplate.java`：

```java
record FigureTemplate(String id, String name, String category, List<String> tags,
                      String desc, String whenNotToUse, List<Param> params,
                      List<String> constraints, String template) {
  record Param(String name, String type, Double min, Double max,
               List<String> options, @JsonProperty("default") String def, String desc) {}
  record Catalog(...不含 template 大字段) {}  // 列表/提示词注入用
}
```

- 参数名即 `\def` 命令名，限 `[a-z][a-z0-9]{0,30}`（防 TeX 注入）。
- 模板 id 限 `[a-z0-9][a-z0-9-]{0,60}`（作文件名）。
- 模板体**不能含 `\def`**（非注释行）：参数声明区由后端按参数值自动生成拼上。模板常带 `%` 注释样例说明参数来源，注释行允许出现 `\def` 字样。
- 坐标由模板内 `\pgfmathsetmacro` 从参数算出，保证数量关系与题干一致。

模板 JSON 示例（`figure_library/figures/right-triangle.json`）：
```json
{
  "id": "right-triangle", "name": "直角三角形", "category": "平面几何",
  "desc": "含一个直角的三角形问题：勾股定理...（≥20字）",
  "params": [
    {"name": "ab", "type": "number", "min": 1, "max": 12, "default": "3", "desc": "直角边 AB 长度"},
    {"name": "rightmark", "type": "bool", "default": "true", "desc": "是否画∠B 的直角记号"}
  ],
  "constraints": ["ab + bc <= 20"],
  "template": "% 参数由系统自动注入：\\def\\ab{3}...\n\\begin{tikzpicture}...\\end{tikzpicture}"
}
```

## 三、后端实现（已完成）

### 新增文件
| 文件 | 作用 |
|---|---|
| `dto/FigureTemplate.java` | 模板/参数/目录 record |
| `service/TikzCompiler.java` | TikZ→PNG 编译器（从 `LangChainController.compileTikz` 抽出复用，图库与生题共用管线） |
| `service/FigureLibraryService.java` | 模板 CRUD + 参数校验 + `\def` 注入 + 渲染 + 约束表达式求值 |
| `controller/FigureLibraryController.java` | `/figure/*` 系列接口 |

### 接口
| 接口 | 作用 |
|---|---|
| `GET /figure/list` | 全部模板目录（不含 template 大字段，图库页与提示词注入共用） |
| `GET /figure/get/{id}` | 完整模板（编辑回显） |
| `POST /figure/save` | 新建/更新；保存前结构校验 + 默认参数试编译，编译不过拒绝入库 |
| `DELETE /figure/delete/{id}` | 删除 |
| `POST /figure/render` | `{id, params}` → 校验+渲染 → `{path}` 或 `{error}` |
| `POST /figure/preview` | `{template, params}` → 草稿渲染（不落盘，图库编辑器实时预览用） |

错误约定：HTTP 200 + `error` 字段（与 `/question/*` 一致），前端按字段区分；结构校验类 `IllegalArgumentException` 经全局异常处理器转 200+error。

### 关键实现点
- **`\def` 注入**（`appendDefs`）：number 原样、bool 转 1/0、string 必须在 options 白名单内。缺省补默认值。
- **约束求值**（`ExprEval`）：双栈 shunting yard，支持 `+ - * / ( ) < <= > >= =`，操作数为参数名/数字。解析失败保守拒绝（返回约束不满足）。`checkConstraintNames` 跳过纯数字常量（修过的 bug：曾把 `ab + bc <= 20` 里的 `20` 当未定义参数）。
- **约束只对 number 参数求值**（修过的 bug：曾把 bool 的 `"true"` 当 double parse 报 400）。
- **ObjectMapper 忽略未知字段**（`FAIL_ON_UNKNOWN_PROPERTIES=false`）：模板 JSON 由人/AI 起草，字段演进不至于整库加载失败。
- **`@JsonProperty("default")`**：record 字段名 `def` 映射 JSON 的 `default`（修过的 bug：文件用 `default`，record 用 `def`，导致加载失败返回 `[]`）。

### 已验证（curl/python 接口测试全过）
- `/figure/list` 返回 2 个样板模板（right-triangle、cuboid）。
- `/figure/render` 两个模板出图正确（ASCII 检视：三角形三边+直角记号、长方体斜二测+虚实线）。
- 错误路径：越界、违反约束、非数字、未知模板、缺省参数，均返回中文 error。
- `/figure/preview` 草稿渲染：正常参数、默认参数、越界、编译错误、空模板，均正确。
- `/figure/save` CRUD 回路：desc 过短拒绝、模板体真写 `\def`（非注释）拒绝、正常保存+删除回路、id 编辑时禁改。

## 七、样板模板（已完成，4 个）
- `right-triangle` 直角三角形（平面几何）：ab/bc/rightmark，约束 ab+bc<=20。
- `isosceles-triangle` 等腰三角形（平面几何）：waist/base/showheight，约束 base<2*waist；可画底边上的高（虚线+垂足 D+直角记号）。
- `general-triangle` 通用三角形（平面几何）：ab/ac/anglea + showangle + 中点 D/E/F + 中线 AD + 中位线三角形；任意形状三角形及常见辅助元素。
- `cuboid` 长方体斜二测（立体几何）：len/wid/hgt，约束 len+wid+hgt<=20。

### 模板设计约定（新增）
- **`coordScale`**：模板级坐标尺度（单位 cm），决定图整体视觉大小，不随参数变化。
- **`\figscale`**：模板内部归一化因子，把图形特征尺寸拉到固定参考值，保证不同参数下图的视觉大小相近。
- 两个尺度都是只缩放坐标，不影响线宽、字体和虚线样式。

> 注意：`right-triangle.json` 曾被 `/figure/save` 回路测试重新格式化（Jackson pretty print），内容不变、仍能渲染。

## 八、已知坑 / 环境备忘
- **`user.dir`**：应用必须从**仓库根目录** `D:/yuanxuan/see` 启动，`figure_library/` 与 `question_output/` 才能定位。从 `seeview/` 启动则 `user.dir=seeview/`，目录找不到返回空列表。
- **端口 8899**：生产实例常驻；测试用 `--server.port=8901`。`TaskStop` 只杀 mvn 包装器，Java 子进程需 `taskkill //PID <pid> //F`。
- **启动方式**（根目录）：`java -cp "seeview/target/classes;$(cat /tmp/cp.txt)" com.yuanxuan.seeview.SeeviewApplication --server.port=8901`，classpath 由 `../mvnw -q dependency:build-classpath -Dmdep.outputFile=/tmp/cp.txt` 生成。
- **中文编码**：curl 在 Windows 控制台发中文会变 GBK 触发 `Invalid UTF-8 start byte`；用 python `urllib` + `PYTHONIOENCODING=utf-8` 测试。
- **模型只支持文本输入**（记忆）：不能 Read 图片验证渲染结果，用 PIL 统计 ink% + 降采样 ASCII 检视。
- **系统代理坑**（记忆）：本机 Clash 系统代理常挂，Python requests 走死代理超时；本地 xelatex 编译不受影响。
