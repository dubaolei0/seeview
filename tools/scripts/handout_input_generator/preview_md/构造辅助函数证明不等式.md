# 构造辅助函数证明不等式

## 把函数不等式转化为差函数最值：

**例 1**（2023年新高考I卷第19题）
**19. 已知函数 $f(x) = a(e^x + a) - x$.**  
**(1) 讨论 $f(x)$ 的单调性；**  
**(2) 证明：当 $a > 0$ 时， $f(x) > 2\ln a + \frac{3}{2}$.**

**例 2**（2021年天津卷第20题）
已知 $a > 0$，函数 $f(x) = ax - xe^x$。

（Ⅰ）求曲线 $y = f(x)$ 在点 $(0, f(0))$ 处的切线方程；

（Ⅱ）证明 $f(x)$ 存在唯一的极值点；

（Ⅲ）若存在 $a$，使得 $f(x) \le a + b$ 对任意 $x \in \mathbb{R}$ 成立，求实数 $b$ 的取值范围。

**例 3**（2024年全国甲卷（文科）第20题）
**20. 已知函数 $f(x) = a(x-1) - \ln x + 1$ .**  

**(1) 求 $f(x)$ 的单调区间；**  

**(2) 当 $a \le 2$ 时，证明：当 $x > 1$ 时， $f(x) < e^{x-1}$ 恒成立.**
