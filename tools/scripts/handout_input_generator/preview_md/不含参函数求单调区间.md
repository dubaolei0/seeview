# 不含参函数求单调区间

## 用导数符号判断函数单调性：

**例 1**（2021年新高考I卷第22题）
**22. （12分）**

已知函数 $f(x) = x(1-\ln x)$.

（1）讨论 $f(x)$ 的单调性；

（2）设 $a, b$ 为两个不相等的正数，且 $b\ln a - a\ln b = a - b$，证明：$2 < \frac{1}{a} + \frac{1}{b} < e$.

**例 2**（2025年北京卷第20题）
20. 已知函数 $f(x)$ 的定义域是 $(-1, +\infty)$，$f(0) = 0$，导函数 $f'(x) = \frac{\ln(1+x)}{1+x}$，设 $l_1$ 是曲线 $y = f(x)$ 在点 $A(a, f(a))(a \neq 0)$ 处的切线。

(1) 求 $f'(x)$ 的最大值；

(2) 当 $-1 < a < 0$ 时，证明：除切点 $A$ 外，曲线 $y = f(x)$ 在直线 $l_1$ 的上方；

(3) 设过点 $A$ 的直线 $l_2$ 与直线 $l_1$ 垂直，$l_1, l_2$ 与 $x$ 轴交点的横坐标分别是 $x_1, x_2$，若 $a > 0$，求 $\frac{2a - x_2 - x_1}{x_2 - x_1}$ 的取值范围。

**例 3**（2022年全国乙卷（文科）第11题）
**11. 函数 $f(x) = \cos x + (x+1)\sin x + 1$ 在区间 $[0, 2\pi]$ 的最小值、最大值分别为 （   ）**

**选项：**
A. $-\frac{\pi}{2}, \frac{\pi}{2}$
B. $-\frac{3\pi}{2}, \frac{\pi}{2}$
C. $-\frac{\pi}{2}, \frac{\pi}{2}+2$
D. $-\frac{3\pi}{2}, \frac{\pi}{2}+2$
