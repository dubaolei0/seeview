# 由导函数图象推原函数性质

## 从导函数正负读原函数单调与极值：

**例 1**（2021年新高考I卷第7题）
**7. 若过点 $(a,b)$ 可以作曲线 $y=e^x$ 的两条切线，则 (    )**

**选项：**
A. $e^b < a$
B. $e^a < b$
C. $0 < a < e^b$
D. $0 < b < e^a$

**例 2**（2024年新高考II卷第11题）
设函数 $f(x)=2x^{3}-3ax^{2}+1$，则（    ）

**选项：**
A. 当 $a>1$ 时，$f(x)$ 有三个零点
B. 当 $a<0$ 时，$x=0$ 是 $f(x)$ 的极大值点
C. 存在 $a,b$，使得 $x=b$ 为曲线 $y=f(x)$ 的对称轴
D. 存在 $a$，使得点 $(1,f(1))$ 为曲线 $y=f(x)$ 的对称中心
